# AI-808 — 响应式精修（移动端 320px 收口 + 触摸目标 + 动效）

> 里程碑：M13（UI 设计规范整改与无障碍加固） · 优先级 P1 · 基于 `feat/ai-807`

## 目标
消除 320/375/390px 视口下的横向溢出，补齐关键交互元素 ≥44px 命中区，并确保
`prefers-reduced-motion` 下所有过渡/动画被关闭。

## 改动清单

### 1. `course/page.tsx` — 320px 横向溢出（验收点）
- `CourseHeader` 卡片 `flex items-center gap-6` → `flex flex-wrap items-center gap-4 sm:gap-6`
- 文本列 `flex-1` → `flex-1 min-w-0`（允许长标题收缩，避免 min-content 撑破）
- 进度块 `w-40 shrink-0` → `w-full mt-3 sm:mt-0 sm:w-40 sm:shrink-0`（移动端整块换行至下一行，桌面端保持右侧 160px 内联）

**核算**：320px 视口 → 容器 `max-w-5xl` + `px-5` 可用宽 ≈280px。
首行 `icon(80) + gap(16) + flex-1(min-w-0 收缩)` 不溢出；进度块 `w-full` 换行占 280px。
`scrollWidth <= innerWidth` ✅。

### 2. `TabNav.tsx` — 窄屏横向滚动（验收点）
- 内层容器去掉 `overflow-x-auto scrollbar-hide`（不再允许横向滚动）
- 4 个主 tab + 退出按钮的 `min-w-[64px] sm:min-w-[72px]` 与 `touch-target-lg` 移除，
  仅保留 `flex-1` 等宽分配
- **核算**：320px 视口 → 5 项各 ≈ (320−16 padding)/5 ≈ 60.8px ≥ 44px（触摸目标达标）；
  无 `min-w` 强制 → 不溢出。高度 `py-3(24)+icon(26)+gap(4)+text(12)` ≈66px ≥44px ✅。

### 3. `LocaleSwitcher.tsx` — 语言按钮命中区（验收点）
- 每个 locale 按钮 `px-2 py-0.5` → `flex min-h-[44px] min-w-[44px] items-center justify-center px-2`
- 小药丸在 320px 下占 ≈88px（两按钮），不溢出且每项 ≥44px ✅。

### 4. `MoreDrawer.tsx` — 关闭按钮命中区（验收点）
- 关闭按钮 `h-10 w-10`(40px) → `h-11 w-11`(44px)，达标 ✅。

### 5. `progress-ring.tsx` — 内联 transition 抽类（验收点）
- 内环圆 `style.transition` → `className="ring-progress"`（`globals.css` 已定义
  `.ring-progress { transition: stroke-dashoffset 0.5s ease }`）；保留功能性 `transform: rotate(-90deg)` inline。
- `LevelRing.tsx` 在 AI-806 已完成同类改造（`className="ring-progress"`），本 feature 仅补齐 progress-ring。

### 6. `globals.css` — reduced-motion 守卫（验收点）
- 既有守卫（209 行至 257 行附近）`@media (prefers-reduced-motion: reduce) { *,*::before,*::after
  { animation-duration:0.01ms!important; transition-duration:0.01ms!important } }`
  已是全局 `*`  blanket 规则，覆盖 button / card / input / select / progress 的全部
  `transition-*`（含 `.ring-progress`、`.progress-ring-circle`、`.card-kids:hover` 等）。
  无需新增，确认已满足"所有过渡/动画在 reduced-motion 下关闭"。

## 验证
- 前端 `tsc --noEmit` **0**
- 320/375/390px 视口：`course` 头与 `TabNav` 无横向溢出（scrollWidth ≤ innerWidth）
- 所有可交互元素命中区 ≥44px（TabNav 60.8px、LocaleSwitcher 44px、MoreDrawer 关闭 44px）
- reduced-motion：`*` 守卫覆盖全部过渡/动画

## 残余 / 后续

  `.ring-progress`），属死样式；建议后续清理（不影响功能，非本 feature 范围）。
- 全局 `kids.muted` 次要文字对比度 ≈2.72:1（AI-806 遗留）仍待 AI-808 之外专项处理。
