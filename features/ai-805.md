# AI-805 — 共享 Dialog 原语（收口三处弹层）

> 状态: done | 栈: node-ts (Next.js 14 App Router / React 18 TSX) | 分支: feat/ai-805
> 来源: 用户诉求（2026-08-18 UI 设计规范审查，M13 首项）— 首页 `MascotStoryModal`、`picture-book` reader modal、`MoreDrawer` 三处各自手写 `fixed inset-0` 弹层，均含 `role="dialog"`/`aria-modal` 但**缺失焦点陷阱、初始焦点、焦点还原**，键盘用户会被困在背景或丢失位置。需收口为单一共享 Dialog 原语，统一无障碍语义。

## 1. 目标

把三处「各自实现的弹层」收口为一个共享 Dialog 原语，统一且正确实现无障碍对话框语义：

1. **统一语义** — 所有弹层容器 `role="dialog"` + `aria-modal="true"` + 可访问名（`aria-label` 或 `aria-labelledby`）。
2. **键盘可达且安全** — 打开时聚焦弹层内首个可聚焦元素；`Tab`/`Shift+Tab` 在弹层内循环（焦点不逃逸到背景）；`Esc` 关闭。
3. **焦点还原** — 关闭后焦点回到触发元素（触发按钮），键盘 / 读屏用户不丢失位置。
4. **遮罩关闭** — 点击遮罩（仅当 `target === currentTarget`）关闭；底部抽屉与居中弹层共用。
5. **零新增依赖** — 不引入 Radix Dialog，焦点管理与键盘处理全部自建（呼应 AI-802「零新增依赖」先例）。

## 2. 现状事实（代码查证）

- `src/components/MoreDrawer.tsx:1` — 手写 `fixed inset-0 z-[70]` 遮罩，含 `role="dialog"`/`aria-modal`，有 `Esc` 的 `useEffect`，但**无焦点陷阱 / 初始焦点 / 焦点还原**；关闭由 `onClick={onClose}` 直接绑在遮罩（未校验 `target===currentTarget`，点面板空白也关）。
- `src/app/[locale]/page.tsx`（`MascotStoryModal`，约 `:467`）— `fixed inset-0 z-50` 遮罩 + 内嵌 `Card`，`role`/`aria-modal` 缺失，`Esc` 无支持，无焦点管理。
- `src/app/[locale]/picture-book/page.tsx`（reader modal，约 `:149`）— `fixed inset-0 z-50` + `bg-black/50`，`role`/`aria-modal` 缺失，`Esc` 无支持，无焦点管理；`{showModal && book && (...)}` 条件渲染，内部直接引用 `book` 非可选。
- `package.json` 无 Radix（`@radix-ui/react-dialog` 不存在），仅 `readdirp` 的无关 `radix` lint 规则 → 自建原语符合「零新增依赖」约定。

## 3. 接口/能力变更

新增 `src/components/ui/dialog.tsx`，导出 `Dialog`（`forwardRef` 式函数组件）与 `DialogProps`：

- `open: boolean` — 受控；`open=false` 渲染 `null`，不在 DOM 残留弹层。
- `onClose: () => void` — `Esc` / 遮罩点击 / 显式调用时触发。
- `children: ReactNode` — 弹层内容（调用方自带 `Card` / 布局）。
- `variant?: "center" | "bottom"` — `center` 居中（默认）| `bottom` 底部抽屉（MoreDrawer）。
- `zIndex?: string` — 遮罩 `z-index` 工具类，默认 `z-50`，抽屉用 `z-[70]`。
- `closeOnBackdrop?: boolean` — 默认 `true`。
- `className?` / `panelClassName?` — 遮罩附加类（如 `bg-black/50` 调整浓度）/ 弹层容器附加类（尺寸、圆角、阴影、滚动由调用方提供）。
- `aria-label?` / `aria-labelledby?` — 二选一的可访问名。
- `dataComponent?` — 透传到遮罩层，保持既有 `data-component` 选择器与 E2E 一致。

内部行为（全部自建）：
- `FOCUSABLE_SELECTOR` + `getFocusable(container)`（过滤可见且非 disabled）。
- `useEffect([open])`：打开时捕获 `prevFocus = document.activeElement`、锁 `body.overflow="hidden"`、`rAF` 聚焦首焦点（或面板）；清理时还原 `overflow` + `prevFocus.focus()`。
- `handleKeyDown`：`Escape`→`stopPropagation`+`onClose`；`Tab`→循环陷阱（首/末焦点包裹；空弹层聚焦面板）。
- `handleOverlayClick`：仅 `target===currentTarget && closeOnBackdrop` 时关闭。

## 4. 实现要点

- **原语**：`src/components/ui/dialog.tsx`（见 §3），自建 focus-trap + `Esc` + 遮罩关闭 + 焦点还原 + body 滚动锁定。
- **MoreDrawer 迁移**（`src/components/MoreDrawer.tsx`）— 删除手写遮罩与 `Esc` `useEffect`，改 `<Dialog open variant="bottom" zIndex="z-[70]" dataComponent="MoreDrawer" aria-label={t("title")} panelClassName="...">`；child-only 抽屉语义由调用方（TabNav）维持不变；内部 4 张 `MoreDrawerCard` 与关闭按钮保留。
- **MascotStoryModal 迁移**（`src/app/[locale]/page.tsx:467`）— 删除手写遮罩，改 `<Dialog open={showStory} onClose={...} dataComponent="MascotStoryModal" aria-labelledby="mascot-story-title" panelClassName="max-w-md w-full">` 包裹原 `Card`；给 `<h3 data-component="MascotStoryTitle">` 加 `id="mascot-story-title"`；Mascot / 标题 / 正文 / `storyTip` / 关闭按钮结构原样保留。
- **picture-book reader modal 迁移**（`src/app/[locale]/picture-book/page.tsx:149`）— 删除手写遮罩，改 `<Dialog open={showModal && !!book} onClose={...} dataComponent="PictureBookModal" aria-labelledby="picture-book-title" className="bg-black/50" panelClassName="...">`；给 `<h2 data-component="PictureBookTitle">` 加 `id="picture-book-title"`；因 Dialog 已用 `open` 门控渲染，内部 `book` 引用全改为 `book?.` 可选链；朗读按钮等结构原样保留。

## 5. 前端实现要点

- 三处弹层全部复用同一 `Dialog`，不再各自写 `fixed inset-0` + `role` + `Esc` 样板。
- `data-component` 钩子（`MoreDrawer` / `MascotStoryModal` / `PictureBookModal` / `ViewGrowthStoryBtn` / `MascotStoryTitle` / `PictureBookTitle` 等）全部保留，既有 E2E 选择器不破。
- i18n 不丢：三处文案仍走 `useTranslations` / `t(...)`。
- `variant="bottom"` 复用同一原语实现抽屉，无需独立 Drawer 组件。

## 6. 关键决策

- **不引入 Radix**：项目约定「零新增依赖」（AI-802 先例），且焦点陷阱逻辑量小、可控、易测，自建更贴合现有 `class-variance-authority` + `cn` 体系。
- **焦点还原用 `document.activeElement` 快照**：在 `useEffect` 打开分支同步捕获触发焦点，清理时 `focus()`；若 `prevFocus` 已脱离文档（`!document.contains`）则跳过，避免报错。
- **初始焦点经 `requestAnimationFrame`**：确保面板已挂载并可聚焦，避免首帧聚焦失败。
- **遮罩关闭用 `target===currentTarget` 校验**：区分「点遮罩」与「点面板」，点面板内空白不误关（修复 MoreDrawer 原 `onClick` 直接 `onClose` 的行为）。
- **picture-book 用 `book?.`**：把 `null` 门控从 JSX 条件搬进 `open` 属性，内部引用统一可选链，更简洁且类型安全。

## 7. 验收标准

- 三处弹层复用同一 `Dialog` 原语（grep 确认 `page.tsx`/`picture-book`/`MoreDrawer` 无独立 `fixed inset-0` 弹层样板）。
- 键盘 `Esc` 可关；`Tab` 在弹层内循环不逃逸到背景；关闭后焦点回到触发元素（`ViewGrowthStoryBtn` / More 触发按钮）。
- `role="dialog"` + `aria-modal="true"` + 可访问名存在（label / labelledby）。
- 前端 `tsc --noEmit` 0。
- E2E（BDD）覆盖 打开 / 关闭 / 遮罩关闭 / `Esc` / 焦点陷阱 / 焦点还原，至少覆盖 `MoreDrawer`（底部）与 `MascotStoryModal`（居中）两路径。
- 语言无关断言（`data-component` / 焦点 DOM 判定），CI 跑 zh。
