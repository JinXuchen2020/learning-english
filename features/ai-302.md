# AI-302 — 录音采集组件（前端 `SpeechRecorder`）

> 状态: in-progress | 栈: node-ts (Next.js 14 + React + Vitest) | 分支: feat/ai-302
> 依赖: — | 前置链: feat/ai-301（在最新分支 feat/ai-301 上建新分支）| 下游: AI-303(评测接口接收 audio)/ AI-307(`/speech` 页嵌入本组件) 消费

## 1. 目标

为 M3「AI 每日口语训练」交付**录音采集**能力：在 `src/components/SpeechRecorder.tsx` 提供可复用的
前端组件，封装 `MediaRecorder` 录音流程（webm/opus 优先、iOS Safari 降级 audio/mp4），支持
**录音时长上限（默认 10s）自动停止**、**麦克风权限引导**与**分级友好错误提示**。所有带分支的
纯逻辑（格式探测、时长钳制、错误分类、结果装配）下沉到 `src/lib/speech-recorder.ts`，由 Vitest
单元测试全覆盖；展示型组件 UI 行为由 AI-307 `/speech` 页的 BDD/E2E 旅程覆盖（见 §6 豁免口径）。

## 2. 接口契约

### 纯逻辑层 `src/lib/speech-recorder.ts`（Vitest node 环境可测，依赖注入）
- `RecordingErrorKind` 联合类型：`'permission-denied' | 'not-supported' | 'no-microphone' | 'insecure-context' | 'unknown'`。
- `classifyRecordingError(error: unknown): RecordingErrorKind` — 从 `DOMException.name` /
  `message` 归类（NotAllowedError/SecurityError/permission→权限拒绝；NotFoundError→无麦克风；
  NotSupportedError→不支持；message 含 permission/deny→权限拒绝；含 microphone/device→无麦克风；
  兜底 unknown）。**纯函数，无浏览器 API 依赖**。
- `pickMimeType(isTypeSupported: (type: string) => boolean): { mimeType: string; isIosFallback: boolean }`
  — 依次探测 `audio/webm;codecs=opus` / `audio/webm` / `audio/ogg;codecs=opus`；均不支持时降级
  `audio/mp4`（iOS Safari：MediaRecorder 存在但不支持 webm）；都不支持返回 `{ mimeType:'' }`
  让浏览器自选默认。**探测函数注入**，node 环境可单测。
- `clampDuration(recMs: number, capMs: number): number` — 非有限/负数→0；超过 cap→cap；否则原值。
- `isSecureContextForMedia(): boolean` — 读 `globalThis.window?.isSecureContext`；无 window（node）
  返回 false。供组件在调用 `getUserMedia` 前预判并给出 insecure-context 友好提示。
- `buildRecordingResult(input: { blob; mimeType; durationMs; createObjectURL? }): RecordingResult`
  — 装配 `{ blob, mimeType, url, size, durationMs }`；`createObjectURL` 注入（默认 `URL.createObjectURL`
  且 try/catch 兜底），node 环境注入 stub 可测；`url` 生成失败降级为空串不抛。
- `RecordingResult` 接口：`{ blob: Blob; mimeType: string; url: string; size: number; durationMs: number }`。
- `DEFAULT_MAX_DURATION_MS = 10_000` 常量导出。

### 展示层 `src/components/SpeechRecorder.tsx`（'use client'）
- Props：`maxDurationMs?`（默认 `DEFAULT_MAX_DURATION_MS`）、`onRecordingComplete?(result: RecordingResult)`、
  `onError?(kind: RecordingErrorKind)`、`disabled?`、`className?`。
- 状态机 `status: 'idle' | 'requesting' | 'recording' | 'recorded' | 'error'`，根元素挂
  `data-component="SpeechRecorder"` 与 `data-status` 供 E2E 钩子（与 `TabNav` 同约定）。
- 行为：
  - `idle`：显示「Tap to record」按钮（Mic 图标）；点击 → 进入 `requesting`。
  - `requesting`：`getUserMedia({ audio: true })`；失败经 `classifyRecordingError` → `error` 并
    调用 `onError`；成功则用 `pickMimeType(MediaRecorder.isTypeSupported.bind(MediaRecorder))`
    创建 `MediaRecorder`（mimeType 为空则不加 mimeType 选项）→ `recording`。
  - `recording`：启动计时（每 100ms 更新 elapsed，UI 显示进度/秒数）；到达 `maxDurationMs` 自动 `stop()`；
    用户点 Stop 立即 `stop()`。`ondataavailable` 收集 chunk；`onstop` 装配 `RecordingResult`
    （durationMs = 实际 elapsed，经 `clampDuration` 兜底）→ 停止轨道 → `recorded` → 调 `onRecordingComplete`。
  - `recorded`：显示 `<audio controls>` 预览 + 「Try again」按钮（重录回到 `idle`，并 `revokeObjectURL`）。
  - `error`：按 `kind` 渲染分级友好文案；`permission-denied` 额外提示去浏览器设置开启麦克风；
    `isIosFallback` 时可在提示中说明格式（audio/mp4）。「Try again」回到 `idle`。
  - 全程 `disabled` 时禁操作。
- 日志：错误经 `logger.warn`/`error`（无裸 console）；与 `lib/logger` 约定一致。
- 样式：复用 `Button`（`@/components/ui/button`）+ Tailwind（`kids-*` / `--seed-primary`），
  圆角、动效与现有 kid-friendly 设计系统一致。

## 4. 风险点

- **无硬路由**：本组件不新增页面路由（路由在 AI-307 `/speech` 落地），因此无独立 BDD/E2E 旅程，
  与 AI-301（纯后端无旅程）同口径，E2E 随 AI-307 交付（见 §6）。
- **MediaRecorder 兼容**：iOS 仅 `audio/mp4`；`pickMimeType` 注入探测函数，node 可测且浏览器真实可用。
- **安全上下文**：`getUserMedia` 需 https/localhost；`isSecureContextForMedia` 预判给 insecure-context 提示。
- **内存**：`recorded` 重录时 `URL.revokeObjectURL` 释放旧 URL，避免泄漏。
- **不越界**：本 feature 仅做采集，不评测/不落库/不接 API（属 AI-303/305/306），不自创需求。
