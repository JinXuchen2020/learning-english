# AI-101 — AiProvider 接口定义（AI 基建 M1）

> 来源: `features/backlog.md` (M1/AI-101) + `docs/ai-integration.md` §六
> 状态: done
> 优先级: P0
> 依赖: —

## 1. 目标

定义 `AiProvider` 抽象接口，统一 LLM / STT / TTS / 发音评测四类能力，使后续 BigModel / NVIDIA / Mock / Azure 等 provider 实现可插拔替换，业务模块只依赖接口。这是 M1 基建的第一块，AI-102 ~ AI-108、M2~M6 全部依赖它。

## 2. 接口契约

文件: `server/src/ai/ai-provider.interface.ts`

### 2.1 方法签名

| 方法 | 输入 | 输出 | 能力 |
|---|---|---|---|
| `chat(messages, options?)` | `ChatMessage[]` + 可选 `ChatOptions` | `Promise<ChatResult>` | LLM 文本对话 |
| `chatWithImage(prompt, image, options?)` | `string` + `ImageInput` + 可选 `ChatOptions` | `Promise<ChatResult>` | 多模态/OCR（GLM-4.6V-Flash） |
| `transcribe(audio, options?)` | `AudioInput` + 可选 `TranscribeOptions` | `Promise<TranscriptResult>` | STT 语音转写 |
| `assessPronunciation(audio, referenceText, options?)` | `AudioInput` + `string` + 可选 `AssessOptions` | `Promise<ScoreResult>` | 发音评测（音素级） |
| `synthesize(text, voice?, options?)` | `string` + 可选 `voice` + 可选 `SynthesizeOptions` | `Promise<AudioResult>` | TTS 语音合成 |

### 2.2 核心类型

- `ChatRole = 'system' | 'user' | 'assistant'`
- `ChatMessage { role: ChatRole; content: string }`
- `ChatResult { text: string; reasoningContent?: string; model?: string; usage?: TokenUsage }`
- `TokenUsage { promptTokens: number; completionTokens: number; totalTokens: number }`
- `TranscriptResult { text: string; confidence?: number; words?: TranscriptWord[]; durationMs?: number }`
- `TranscriptWord { word: string; startMs: number; endMs: number; confidence?: number }`
- `ScoreResult { score: number; readableText: string; weakPhonemes: string[]; feedback: string; mascotExpr: MascotExpression }`
- `AudioResult { audioBase64?: string; audioUrl?: string; mimeType: string; durationMs?: number }`
- `MascotExpression = 'happy' | 'encourage' | 'thinking' | 'cheer'`
- `ImageInput { data: string; mimeType: string }`（base64，不含 data: 前缀）
- `AudioInput { data: Buffer | string; mimeType: string }`

### 2.3 常量

- `AI_PROVIDER_TOKEN = 'AI_PROVIDER'`（NestJS 注入 token）
- `ProviderName = 'bigmodel' | 'nvidia' | 'mock' | 'azure'`

## 3. 数据模型

纯 TypeScript 接口/类型，无数据库实体（实体在 AI-102/201/301/401/501 各自 feature 落地）。

## 4. 验收标准

- [ ] `server` 在 `tsc --noEmit`（strict: noImplicitAny / strictNullChecks）下零错误
- [ ] 接口与所有导出类型均有 JSDoc 注释（方法级 + 关键类型级）
- [ ] 类型覆盖 LLM（chat/chatWithImage）、STT（transcribe）、TTS（synthesize）、发音评测（assessPronunciation）四类能力
- [ ] 不引入任何具体 provider 依赖（仅类型与抽象），AI-102 再实现 BigModel

## 5. 风险点

- **推理模型响应结构**：BigModel 推理模型返回 `reasoning_content` + `content`，接口 `ChatResult` 已预留 `reasoningContent` 字段，provider 实现只读 `content`。
- **超时/限流**：接口方法本身不做重试（重试封装在 AI-106 的 provider 调用层），此处保持纯契约。
- **跨 provider 差异**：`assessPronunciation` 在 Mock/Azure 缺失时由 AI-305 提供"转写相似度兜底"，接口统一输出 `ScoreResult`。
