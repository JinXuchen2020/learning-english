# AI-502 — 每日 AI 报告聚合接口（`POST /api/ai/report/daily`）

> 状态: in-progress | 栈: node-ts (NestJS 10 + TypeORM) | 分支: feat/ai-502（基于 feat/ai-501）
> 依赖: AI-106（AiProvider.chat 抽象）、现有 ProgressModule 数据实体、AI-501（AiReport 实体 + 仓库）| 下游: AI-503（ReportAgent 系统提示精炼）/ AI-504（Home「今日 AI 小结」卡片）/ AI-505（自动触发）/ AI-506（家长周报）

## 1. 目标

落地 M5「AI 错题与进度报告」的**聚合与生成接口**：`POST /api/ai/report/daily`。
接收 `userId` 与可选 `date`，聚合该儿童当日学习统计（任务完成 / 单词练习 / 课程完成 / 口语尝试与平均分），
据此生成（或返回已有）每日 AI 小结并落库到 `ai_reports`（AI-501 实体）。

两条核心验收（来自 backlog）：
- **无学习数据时返回友好默认报告**（不调 AI，省 token，且仍持久化以保证当日幂等）。
- **有数据时含真实统计**（调用 `AiProvider.chat(ReportAgent)`，把真实统计喂给模型，输出鼓励语气小结）。

## 2. 接口契约

### 路由
- `POST /api/ai/report/daily`（全局前缀 `api`，见 `main.ts` 的 `setGlobalPrefix('api')`）。
- 鉴权：**不加 `JwtAuthGuard`**——与现有 `AiController`（`ai/speech`，AI-303）保持一致；
  该模块鉴权按计划文档「留待后续」，userId 由请求体 `userId` 字段传入（与 `speech-evaluate.dto.ts` 的 `dto.userId` 同口径）。
  > 已知限制（继承自 AI 模块约定，非本 feature 引入）：userId 客户端传入、未鉴权隔离；待全局鉴权落地后统一收紧。

### 请求体 `GenerateDailyReportDto`
- `userId: string`（必填，非空）——报告归属儿童。
- `date?: string`（可选，`YYYY-MM-DD`）——报告日期（本地日）；缺省取**服务端 UTC 当日**（与 `task_completions.date` 的 UTC 口径一致：`new Date().toISOString().split('T')[0]`）。

### 响应 `DailyReportResponse`
```
{
  id?: string;            // 已落库报告 id（降级默认未持久化时为 undefined）
  userId: string;
  date: string;
  summaryText: string;    // 鼓励语气总体小结
  weakWords: string[];    // 弱项单词清单（AI 输出；默认 []）
  suggestionText: string; // 明日建议（默认友好提示）
  isDefault: boolean;     // true = 友好默认报告（无活动或 AI 失败降级），false = AI 真实生成
  mascotExpr?: 'happy'|'encourage'|'thinking'|'cheer'; // 来自 ReportAgent，驱动前端狐狸动画（AI-504）
  stats: DailyReportStats | null; // 真实统计（返回已有报告时为 null，因其是生成时快照）
  createdAt?: string;
}
```

## 3. 聚合口径（当日统计）

`AiReportService.getDailyStats(userId, date)` 注入以下仓库（均在 `appEntities` 且于 `AiModule.forFeature` 注册，沿用 AI-501 的 `@Global` 仓库复用模式）：

| 统计字段 | 来源实体 | 计算 |
|---|---|---|
| `taskComplete` | `TaskCompletion` | `count({ where: { userId, date } })`（字符串 `date` 列直接等值） |
| `wordsPracticed` | `WordProgress` | 当日 `lastPracticedAt` ∈ [dayStart, dayEnd] 的行数 |
| `lessonsCompleted` | `LessonProgress` | 当日 `completed=true` 且 `completedAt` ∈ 当日窗口的行数 |
| `speechAttempts` | `AiSpeechAttempt` | 当日 `createdAt` ∈ 当日窗口的行数 |
| `avgSpeechScore` | `AiSpeechAttempt` | 当日口语分均值（四舍五入；无口语尝试时为 `null`） |

> 对应 backlog 的「attempts / speechScores / taskComplete」：`attempts` = `wordsPracticed + speechAttempts`，`speechScores` = `speechAttempts + avgSpeechScore`，`taskComplete` = `taskComplete`。

日期窗口：`dayBounds(date) => [${date}T00:00:00.000Z, ${date}T23:59:59.999Z]`，用 TypeORM `Between` 过滤 `Date` 列（`lastPracticedAt`/`completedAt`/`createdAt` 均为 nullable，自动排除 null）。

## 4. 生成流程（幂等 + 降级）

`AiReportService.generateDailyReport(userId, date?)`：
1. `date` 缺省取 UTC 当日。
2. **幂等查已有**：`findOne({ where: { userId, date } })` 命中→直接返回已有报告（`isDefault=false`、`stats=null`，快照语义）。AI-505 的「完成触发一次 / 不重复生成」即依赖此分支。
3. 聚合 `stats`。
4. **无活动**（`taskComplete/wordsPracticed/lessonsCompleted/speechAttempts` 全为 0）→构造友好默认报告（`buildDefaultReport`），**持久化**后返回（`isDefault=true`）。省去无意义的 AI 调用。
5. **有活动**→`callReportAgent(stats)`：`AiProvider.chat([system: REPORT_AGENT_SYSTEM_PROMPT, user: JSON(stats)])` → `parseReportAgentOutput(text)` 解析结构化 JSON → 映射为 `AiReport` 字段 → 持久化 → 返回（`isDefault=false`、`mascotExpr` 透传）。
6. **AI 失败**（provider 抛错）→`logger.warn` 降级为友好默认报告返回（`isDefault=true`），**不持久化**（避免把降级内容缓存当天，下次可重试）。
7. **唯一约束 race**（并发同 (userId,date) 落库）→`persistReport` 捕获 `QueryFailedError`（SQLITE_CONSTRAINT_UNIQUE）→回查已有返回，保证不 500。

## 5. ReportAgent 与 AI-503 的接缝

AI-502 定义 `report-agent.ts`：
- `REPORT_AGENT_SYSTEM_PROMPT`：**可用默认 prompt**（要求模型输出严格 JSON：`{ summaryText, weakWords[], suggestionText, mascotExpr }`，中文鼓励语气、不批评、弱项取自真实统计）。
- `ReportAgentOutput` 接口 + `parseReportAgentOutput(text)`（鲁棒解析：剥离 ```json 围栏、截取首个 `{...}`、字段缺失给默认、非数组 weakWords 兜底 `[]`）。
- 完整「系统提示精炼 / 输出 JSON Schema 校验」是 **AI-503** 的交付；AI-502 仅提供可工作的默认实现与该接缝，不预写 AI-503 的细节（不自创需求）。

## 6. 验收标准

- [ ] `POST /api/ai/report/daily` 200 返回 `DailyReportResponse` 结构。
- [ ] 无当日活动 → 返回 `isDefault=true` 的友好默认报告，且已落库（幂等）。
- [ ] 有当日活动 → 返回 `isDefault=false`、`stats` 含真实统计、`summaryText/weakWords/suggestionText` 来自 AI 输出。
- [ ] 同日重复调用 → 返回已有报告（唯一约束兜底），不重复生成。
- [ ] AI 调用失败 → 降级默认（`isDefault=true`）且不持久化，接口不 500。
- [ ] `nest build`/`tsc` 0 错误；jest 全绿；`seed` 不抛；pre-commit 质量门强执通过。

## 7. 风险点

- **模块边界**：`TaskCompletion`/`WordProgress`/`LessonProgress` 本属 Tasks/Progress 模块，AI-502 在 `@Global` 的 `AiModule.forFeature` 二次注册其仓库（与 `Word`/`Sentence`/`AiSpeechAttempt` 已被 AI 模块注册的先例一致），避免改动其他模块公共 API；`ai.module.spec.ts` 同步补 3 个假 repo override（同 AI-501 模式）。
- **日期口径**：所有当日判定统一用 UTC `YYYY-MM-DD` 字符串（与 `task_completions.date` 一致），避免时区错位。
- **JSON 解析鲁棒性**：LLM 输出可能带围栏/多余文本，`parseReportAgentOutput` 必须兜底，杜绝解析崩溃导致 500。
- **降级不缓存**：AI 失败路径不持久化，否则瞬态失败会被当天缓存为默认。
