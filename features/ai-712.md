# AI-712 — 家长仪表盘（多孩子进度总览）

> 状态: done | 栈: node-ts（NestJS 后端 + Next.js 前端，全栈） | 分支: feat/ai-712
> 来源: `features/backlog.md` M8 / AI-712；用户设想：家长一眼看全部孩子的学习进度。

## 1. 目标

在 AI-710（家庭绑定，已有 `parentId` 归属）之上，提供**家长视角的多孩子进度总览**：

- 家长面板首页以卡片网格展示名下每个孩子：昵称、等级、累计星星、连续天数、学习计划完成度、近期活跃。
- 点开某孩子卡片 → 进度详情：薄弱单词 Top（来自 `ai_reports` / `word_progress`）、各技能掌握度、周趋势（复用 AI-507 单孩报告形态，扩展到多孩路由）。
- 数据全部已按 `userId` 落库（`LessonProgress` / `WordProgress` / `StudyPlan` / `AiReport` / `User.totalStars` 等），本 feature 仅做「按 `parentId` 聚合 + 前端可视化」。

用户价值：把分散在单孩视角（AI-507）里的进度，收敛到家长账号统一入口，契合「家长 = 家庭枢纽」模型。

## 2. 接口契约

### 2.1 后端（挂 `ParentGuard`）

| 方法 | 路径 | 说明 | 响应 |
|---|---|---|---|
| GET | `/parent/dashboard` | 列出本人名下每个孩子的进度摘要 | `ChildProgressSummary[]` |
| GET | `/parent/children/:childId/progress` | 单孩详情（趋势 + 薄弱词 + 计划） | `ChildProgressDetail` |

- `ChildProgressSummary`：`childId, nickname, level, totalStars, streakDays, planCompletionRatio(number 0..1), lastActiveDate, hasProviderOverride(预留 AI-711)`。
- `ChildProgressDetail`：`summary`(同上) + `weakWords: { word; wrongCount }[]`(取最新 `ai_reports.weakWords` 或聚合 `word_progress` 错次) + `skillMastery: { skillType; ratio }[]`(来自 `lesson_progress` 按 `skill_type`) + `weeklyTrend: { date; stars }[]`(近 7 日 `ai_usage`/`task_completion` 聚合)。
- 校验：`childId` 必须 `parentId === req.user.userId`，否则 403/404（防越权看别家孩子）。
- 复用 AI-507 `parent-report` 的聚合逻辑抽成 `ProgressAggregationService`，供单孩 / 多孩共用。

### 2.2 前端

- 家长页 `src/app/parent/page.tsx` 顶部改为「家庭总览」：孩子卡片网格（响应式 `grid`），复用 cozy-kids `Card` / `Badge` / `ProgressRing` 原语（见 `docs/design-system.md`）。
- 卡片点击 → 路由到 `/parent/children/:childId`（新页）或就地展开 `ChildProgressDetail` 抽屉：薄弱词列表（可点下钻到单词）、技能掌握度条、周趋势小图。
- 空态：无孩子时提示「去添加孩子」（引导 AI-710 流程）。

## 3. 数据模型

- **零新增表**：全部聚合现有实体。
  - `User`（totalStars / streakDays / level / parentId）
  - `study_plans` / `study_plan_days`（planCompletionRatio）
  - `ai_reports`（weakWords JSON）
  - `word_progress` / `lesson_progress`（掌握度 / 错次）
  - `task_completion`（周趋势）
- 如需稳定聚合，可在 `ProgressAggregationService` 内做只读查询，不改写任何表。

## 4. 与既有 feature 的衔接

- 依赖 AI-710：`parentId` 归属是列表 / 聚合的前提。
- 复用 AI-507 的「家长报告」聚合与可视化形态（单孩 → 多孩路由参数化），避免重复造图表。
- 与 AI-711 的 `hasProviderOverride` 字段握手：总览卡片可显示「独立配置 / 沿用默认」标识。

## 5. 验收标准

- [ ] 家长登录后看到名下所有孩子进度卡片（星星 / 连续天数 / 计划完成度）。
- [ ] 点开孩子可看薄弱词 Top、技能掌握度、周趋势，数据与库一致。
- [ ] 越权访问他人孩子 `:childId/progress` → 403/404。
- [ ] 无孩子时空态引导到添加流程。
- [ ] 单元 + BDD/E2E 覆盖（见 §7）。

## 6. 测试计划（硬约束 #6）

### 6.1 单元测试
- `progress-aggregation.service.spec.ts`：多孩子聚合返回各自正确摘要；`weakWords` 取最新报告；`planCompletionRatio` 计算正确；越权 childId 拒绝。
- `parent.controller.spec.ts`（dashboard 端点）：ParentGuard 拒绝儿童 JWT；跨家长访问 403。

### 6.2 BDD/E2E
- 场景：家长建 2 孩子并完成若干任务 → 家长进仪表盘 → 看到 2 张进度卡（星星/连续天数不同）→ 点开孩子A → 薄弱词与趋势正确 → 用另一家长账号访问孩子A 详情 → 403。

## 7. 风险点

| 风险 | 缓解 |
|---|---|
| 聚合性能（多孩大表） | 只读聚合 + 必要索引（parentId / userId / createdAt）；趋势限近 7 日 |
| 越权看别家孩子 | `childId` 强制校验 `parentId === JWT.userId` |
| 与 AI-507 单孩报告重复 | 抽 `ProgressAggregationService` 共用，UI 复用同一图表组件 |
| 空态 / 新生儿无数据 | 友好空态 + 引导添加孩子 |
