# AI-507 家长报告 Dashboard

> 里程碑：M5（AI 错题与进度报告）· 优先级 P1 · 依赖 AI-506（WeeklyReportData + `POST /api/ai/report/weekly`）
> 更新：2026-08-07

## 1. 目标与范围

家长视角的 Web 页，按周查看孩子的学习情况：**趋势图表**、**弱项 Top10（可点击下钻到单词）**、**AI 建议**。复用 AI-506 `WeeklyReportService.buildWeeklyReport` 的聚合结果，新增一个**只读预览端点**（不发送邮件），前端渲染可视化 Dashboard。

- 路由：`/parent-report`（App Router 页面，AuthGate 包裹，复用已登录 child 的 `user.id`）。
- 数据来源：`GET /api/ai/report/weekly/preview?userId=&weekStart=`（新增，**不加 guard**，与 AI-502/504/506 同口径；仅聚合不发送）。
- 周切换：prev/next 周（客户端 ±7 天，调用同一端点传不同 `weekStart`）。
- 弱项下钻：点击弱项单词 → 导航到 `/practice?focusWord=<text>`，practice 页聚焦该单词（AI-507 在 `app/practice` 增加 `focusWord` 支持）。

## 2. 验收标准

1. **图表渲染趋势**：Dashboard 渲染一周（7 天）学习趋势图（`masteryTrend`：每日任务完成数 + 口语平均分）。
2. **弱项列表可点击下钻到单词**：弱项 Top10 中点击任一单词 → 进入 `/practice` 并聚焦该单词。
3. 指标卡展示 ≥4 项（活跃天数 / 完成任务 / 练习单词 / 完成课程 / 口语跟读 / 平均口语分）。
4. AI 建议列表渲染（汇集本周每日建议）。
5. 周切换可查看不同周（prev/next）。
6. `next build` 成功；前端 tsc 0 错；vitest（纯逻辑）全绿；BDD/E2E 覆盖趋势图渲染 + 弱项下钻；四道质量门 PASSED。

## 3. 后端：只读预览端点（不发送邮件）

`ai-weekly-report.controller.ts`（`@Controller('ai/report')`）新增：
```ts
@Get('weekly/preview')
async preview(@Query('userId') userId: string, @Query('weekStart') weekStart?: string) {
  if (!userId) throw new BadRequestException('userId is required');
  return this.weeklyReportService.buildWeeklyReport(userId, weekStart);
}
```
- 与现有 `@Post('weekly')`（发送邮件）路径不同（`weekly/preview` vs `weekly`），方法不同，无冲突。
- 返回 `WeeklyReportData`（含 `metrics / weakWordsTop / masteryTrend / dailySummaries / suggestions / html`，前端只取前几项）。
- `userId` 校验缺省 → `400`（class-validator 对 query 不生效，手动校验）。
- 不加 `JwtAuthGuard`，与 AI-502/504/506 一致；家长 PIN 模式收口留待 AI-702。
- 单测：`ai-weekly-report.controller.spec.ts` 增加 `preview` 用例（调用 `buildWeeklyReport`、缺 `userId` 抛 `BadRequestException`）。

## 4. 前端：类型 / API / 纯逻辑

`lib/types.ts` 增加（与后端 `weekly-report.service.ts` 接口对齐）：
- `WeeklyReportMetrics` / `MasteryTrendPoint` / `DailySummary` / `WeeklyReportData`。

`lib/api.ts` 增加：
```ts
export function getWeeklyReport(userId: string, weekStart?: string): Promise<WeeklyReportData> {
  const params = new URLSearchParams();
  params.set('userId', userId);
  if (weekStart) params.set('weekStart', weekStart);
  return request<WeeklyReportData>(`/ai/report/weekly/preview?${params.toString()}`);
}
```

`lib/weekly.ts`（**纯逻辑，带 vitest 单测**，满足「前端仅纯逻辑模块需单测」约定）：
- `mondayOfWeekUTC(date): string` — 返回 `date` 所在周 Monday（UTC，YYYY-MM-DD），与后端 `weekStartOf` 口径一致。
- `addDaysUTC(date, n): string` — UTC 加减天。
- `weekEndOf(ws): string` — `ws + 6`。
- 供 Dashboard 初值（本周 Monday）与 prev/next 周导航复用。

## 5. 前端：可视化组件与页面

### 5.1 `components/TrendChart.tsx`（新增，轻量 SVG，零图表依赖）
- props：`points: MasteryTrendPoint[]`。
- 渲染：7 根柱状（每日 `taskComplete`，按比例）+ 一条折线（`avgSpeechScore`，null 点断开连接）。
- 坐标：viewBox `0 0 320 160`；data-component=`TrendChart`；柱 `data-bar="task"`、折线 `data-trend-line="score"`，便于 E2E 断言「图表渲染趋势」。
- 与项目「不引新依赖」取向一致（图表用原生 SVG，不引 recharts/echarts）。

### 5.2 `app/parent-report/page.tsx`（新增）
- `AuthGate` 包裹；`useAuth()` 取 `user.id`。
- 状态：`weekStart`（初值 `mondayOfWeekUTC(today)`）、`data`、`loading`、`error`。
- 装载：mount + `weekStart` 变化 → `getWeeklyReport(user.id, weekStart)`。
- 渲染区（均带 `data-component`）：
  - 标题区：`/parent-report` 头部（吉祥物 + 「家长报告」+ 孩子名 + 周区间 `weekStart~weekEnd`）。
  - 周切换：`prev`/`next` 按钮（`weekStart` ±7），`data-component="WeekNav"`。
  - 指标卡：`metrics` 6 项网格，`data-component="MetricCard"`。
  - 趋势图：`<TrendChart points={data.masteryTrend} />`，`data-component="TrendSection"`。
  - 弱项 Top10：列表，`data-component="WeakWordItem"` 的 `<Link href={'/practice?focusWord='+encodeURIComponent(w)}>`，`data-weak-word={w}`。
  - AI 建议：`suggestions` 列表，`data-component="SuggestionItem"`。
  - loading / 空态（无数据）。

### 5.3 `components/TabNav.tsx`
- 增加第 7 个 tab：`{ href: '/parent-report', label: '报告', icon: BarChart3 }`，使 Dashboard 经客户端点击可达（E2E 需 client-side 导航以保住内存 token，且 AuthGate 页禁 `page.goto`）。

### 5.4 `app/practice/page.tsx`（弱项下钻目标，最小改动）
- `useSearchParams` 已存在；新增 `focusWord = searchParams.get('focusWord')`。
- 单词装载完成后，若 `focusWord` 命中某 `word.text`（不区分大小写），`setCurrentIndex(idx)` 跳到该词；并在 WordCard 加 `data-component="QuizWordText"`（含 `word.text`）便于 E2E 断言下钻落地。
- `focusWord` 缺省时行为完全不变（不影响现有 practice E2E）。
