# AI-810 · i18n 文案遗漏收口（硬编码英文 / 字面键）

> 里程碑：M13（UI 设计规范整改与无障碍加固） · 优先级 P2 · 分支 `feat/ai-810`（基于 `feat/ai-809`）

## 背景 / 动机
AI-706 已落地全站 i18n（next-intl，中英双语，单词/学习内容保持英文），但扫描式复查发现 `practice` 页庆祝屏仍有三处硬编码英文 UI 串（`"Amazing Job!"` / `"Practice Again"` / `"Back to Course"`），且练习页内联动物插画的 `aria-label` 为硬编码英文描述句（如 `"A cute cat"`）。这些串在切到英文→中文时不会跟随切换，违反「全站 UI 文案可中/英切换（单词内容除外）」的验收口径。本 feature 收口这些遗漏，并全站 grep 清零其他裸英文 UI 串。

## 改动清单

### 1. 练习页庆祝屏（`src/app/[locale]/practice/page.tsx:351`）
- `<h2>Amazing Job!</h2>` → `{t("amazingJob")}`。
- 成绩摘要句（含加粗高亮的答对数量）改用 `t.rich` 富文本插值，保留原 `--color-success` 加粗样式：
  - `t.rich("quizCompleteSummary", { correct, total, strong: (chunks) => <span className="font-extrabold text-[var(--color-success)]">{chunks}</span> })`
  - 一句话整体翻译，避免拆句导致中英文语序错位。
- `Practice Again` 按钮 → `{t("practiceAgain")}`。
- `Back to Course` 按钮 → `{t("backToCourse")}`（复用既有 `Practice.backToCourse` 键，与空态返回按钮一致）。

### 2. 词汇插画可访问名（`src/app/[locale]/practice/page.tsx:63` 等 10 处）
- `WordIllustration` 内 10 个硬编码 `aria-label="A cute cat"` / `"A happy dog"` / … 改为 `aria-label={word}`（与既有的兜底分支 `aria-label={word}` 对齐）。
- `word` 即所教词汇（如 `Cat`/`Dog`，由 `item.word.text` 传入），属**学习内容**，按 i18n 约定保持英文原样；同时消除硬编码英文描述句，使图片可访问名 = 词汇本身，对读屏更友好且随内容一致。

### 3. i18n 键
- 新增 `Practice.amazingJob` / `Practice.practiceAgain` / `Practice.quizCompleteSummary`（en/zh）。
- `quizCompleteSummary` 含 `<strong>{correct}</strong>` 富文本标签，中英文均使用，由 `t.rich` 的 `strong` 渲染函数套用加粗高亮样式。

## 验证
- 前端 `tsc --noEmit` **0**。
- `src/messages/{en,zh}.json` 解析通过（新增键结构一致）。
- 全站裸英文 UI 串 grep 清零（见下「扫描范围」）。
- 结构与类型层验证：`amazingJob`/`practiceAgain`/`backToCourse` 为纯文本键，正常插值；`quizCompleteSummary` 经 `t.rich` 渲染，`strong` 回调返回带样式的 `<span>`，中英文均显示「X / Y 个单词」式成绩摘要。

## 扫描范围（裸英文 UI 串排查）
- JSX 文本子节点（大写/小写起始、≥6 字符）：仅命中原 `Amazing Job!`，已全部收口 → 复扫 0 命中。
- 属性 `aria-label` / `placeholder` / `title` / `alt` 含英文：原命中 10 处动物插画 `aria-label`，已全部改 `{word}` → 复扫 0 命中。
- 客户端 `.ts` 逻辑中的用户可见英文（`toast` / `setError` / `alert` 等）：0 命中。
- `logger.error(...)` 英文串为开发者日志（LOG-101 约定日志保持技术性英文，不在 UI 文案范围），未计入。
- `data-component` 标识串为测试/可访问性钩子，非 UI 文案，未计入。

## 范围与边界
- 仅处理 UI chrome 文案；单词/句子/词汇插画内容保持英文（i18n 约定），`aria-label={word}` 即内容本身。
- 未引入新依赖、未改动 i18n 框架与路由；`t.rich` 为 next-intl ^3.26.5 原生能力。
