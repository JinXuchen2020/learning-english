# AI-506 家长周报（邮件 / 推送）

> 里程碑：M5（AI 错题与进度报告）· 优先级 P1 · 依赖 AI-502（每日报告聚合）、User.parentEmail
> 更新：2026-08-07

## 1. 目标与范围

每周聚合儿童一周（`ai_reports` + 当日统计）生成一份**家长周报**，含 ≥4 项指标（活跃天数 / 完成任务 / 练习单词 / 完成课程 / 口语跟读 / 平均口语分），渲染为自包含 HTML 邮件，发送给家长邮箱，并持久化发送记录**可追溯**。

- 触发方式（与 AI-505 同构）：
  - **按需**：`POST /api/ai/report/weekly`（家长 Dashboard / 调试可触发，接受 `recipientEmail` 覆盖）。
  - **自动**：扩展 AI-505 `ReportSchedulerService`，每周固定日/时（默认周日 20:00）扫描所有含 `parentEmail` 的用户生成并发送。
- **本 feature 不新建前端 UI**（家长可视化 Dashboard 属 AI-507）。纯后端能力，复用已落库的每日报告数据。

## 2. 验收标准

1. 周报内容含 **4 项以上指标**（活跃天数、完成任务数、练习单词数、完成课程数、口语跟读次数、平均口语分）。
2. 邮件发送**成功可追溯**：每条发送落 `ai_parent_email_logs`（to / subject / status / weekStart / htmlPath / errorText / sentAt）。
3. 无 `parentEmail` 的用户在扫描中被**安全跳过**（不报错、不阻整轮）。
4. 同一周重复触发生成不重复发信（weekStart 维度去重见 §5）。
5. `nest build` 0 错；jest 全绿；四道质量门 PASSED。

## 4. 邮件抽象（无新外部依赖）

为保持测试隔离、不引入 SMTP 依赖（与 AI-505 不用 `@nestjs/schedule` 同取向）：

- `email-sender.interface.ts`：`EMAIL_SENDER_TOKEN` + `EmailSendOptions` + `EmailSendResult` + `EmailSender` 接口。
  ```ts
  interface EmailSendResult { messageId: string; accepted: boolean; htmlPath?: string }
  ```
- `log-email-sender.service.ts`（`LogEmailSender implements EmailSender`，默认实现）：
  将 HTML 写入 `server/logs/emails/<ISO时间戳>-<sanitized-to>.html`（`mkdir recursive`），返回 `{ messageId: 'log-<ts>', accepted: true, htmlPath }`。**零外部依赖、可离线、可断言**。
- `email.service.ts`（`EmailService`）：注入 `EMAIL_SENDER_TOKEN`，暴露 `sendWeeklyReport({ to, subject, html, userId, weekStart })` 委托给 sender。
- `AiModule` 注册 `{ provide: EMAIL_SENDER_TOKEN, useClass: LogEmailSender }`。
- **真实 SMTP 发送为环境门控扩展点**（见 `docs/quality/ai-506-gate.md`）：未来加 `SmtpEmailSender`（`nodemailer`/`jsonTransport`）一行切换，不影响本 feature 逻辑。

## 5. `WeeklyReportService`（聚合 + 渲染 + 发信）

`server/src/ai/weekly-report.service.ts`，注入 `AiReportService`（复用 `getDailyStats`）、`User` 仓库、`AiReport` 仓库、`AiParentEmailLog` 仓库、`EmailService`。

- `weekStartOf(date): string`：返回 `date` 所在周的 **Monday**（ISO 周起始）`YYYY-MM-DD`；窗口 = `[ws, ws+6]`（7 天）。
- `buildWeeklyReport(userId, weekStart?): Promise<WeeklyReportData>`：
  - 对 7 天逐日调 `aiReportService.getDailyStats`（每日用 `try/catch`，单日失败不致命）。
  - 聚合：
    - `activeDays`：有活动的天数（taskComplete/wordsPracticed/lessonsCompleted/speechAttempts 任一 >0）。
    - `totalTasksCompleted / totalWordsPracticed / totalLessonsCompleted / totalSpeechAttempts`：7 日求和。
    - `avgSpeechScore`：7 日 `avgSpeechScore` 非 null 的均值四舍五入（无则为 null）。
    - `weakWordsTop`：汇集 7 日 `weakWordCandidates`，按出现频次排序取 Top10。
    - `masteryTrend`：`[{ date, avgSpeechScore, taskComplete }]`（供 AI-507 图表）。
    - `dailySummaries`：`AiReport` 本周行 → `{ date, summaryText, suggestionText, isDefault }`。
    - `suggestions`：汇集非空的 `suggestionText`。
  - 渲染 `renderHtml(data)`：cozy-kids 自包含 HTML（内联样式、狐狸吉祥物、指标卡、弱项 Top10、每日亮点、建议、落款）。返回 `WeeklyReportData`（含 `html`）。
- `generateAndSendWeeklyReport(userId, opts?: { weekStart?, recipientEmail? })`：
  - 取 user；无 → `{ skipped:true, reason:'user-not-found' }`。
  - 收件人 = `opts.recipientEmail || user.parentEmail`；无 → `{ skipped:true, reason:'no-recipient', weekStart }`。
  - `buildWeeklyReport` → `subject = 【狐狸英语】${nickname} 的本周学习周报 (${ws} ~ ${we})`。
  - `emailService.sendWeeklyReport(...)`；成功落 `AiParentEmailLog(status:'sent', htmlPath)`；抛错落 `status:'failed', errorText`，返回 `{ success:false }`（**不向上抛**，调度整轮不中断）。
  - 同周幂等：调用方（端点/调度）以 weekStart 维度去重（本 feature 不重复发同一 weekStart；未来可在端点层做 `findOne` 已发则跳过——本版依赖「先查后发」，见 gate 文档）。

## 7. 调度扩展（AI-505）

`report-scheduler.service.ts` 注入 `WeeklyReportService`：
- 新增 env：`WEEKLY_REPORT_DAY`(0..6, 默认 0=周日)、`WEEKLY_REPORT_HOUR`(默认 20)、`WEEKLY_REPORT_ENABLED`(默认开启，`'false'` 关)。
- `computeMsUntilNextWeekday(dayOfWeek, hour, now)`：距下个目标「周几:小时」的毫秒。
- `runWeeklySweep()`：遍历 users；**仅 `parentEmail` 非空**者调 `generateAndSendWeeklyReport`（其余 `logger.info` 跳过）；逐用户 `try/catch`。
- `onModuleInit`：`NODE_ENV==='test'` 跳过；`REPORT_SWEEP_ENABLED!=='false'` 启动每日、`WEEKLY_REPORT_ENABLED!=='false'` 启动每周（独立 timer/interval）。`onModuleDestroy` 清除全部定时器。
