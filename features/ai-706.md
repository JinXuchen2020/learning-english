# AI-706 — 多语言化（国际化 i18n，next-intl + `[locale]` 路由）

> 状态: done | 栈: node-ts（Next.js 14 App Router + React 18）| 分支: feat/ai-706
> 关联 backlog: 全站 UI 文案可中/英切换；默认中文；单词与学习内容保持英文原样；儿童/家长模式均双语可用。

## 1. 目标

前端引入 i18n，支持 **中文 / 英文** 一键切换，默认语言 **中文**；覆盖全站页面与组件（登录/首页/练习/计划/家长/奖励/聊天/绘本/拍照/口语/卡片/报告）的 **UI chrome**；单词与学习内容（API 返回的英文单词、释义、故事、题目）**不翻译**。儿童模式与家长模式均双语可用。

## 2. 方案（已与用户确认）

- **库**：`next-intl` v3（App Router `[locale]` URL 前缀路由：`/zh/...`、`/en/...`）。
- **默认语言**：`zh`；中间件负责 locale 协商（未带前缀 → 重定向到默认 `zh`）。
- **语言选择器**：顶部/设置区切换 zh/en，经 next-intl cookie（`NEXT_LOCALE`）持久化，中间件读取；刷新后仍生效。
- **不翻译范围**：单词、释义、例句、故事、题目等学习内容保持英文；仅 UI chrome（按钮/标题/标签/空态/提示/toast/导航）翻译。

## 3. 接口契约 / 前端改造

### 3.1 路由重构（高风险，已确认 next-intl 改路由）

- 删除根 `src/app/layout.tsx`（其 `<html lang>` + `AuthProvider` + `TabNav` 迁移）。
- 新建 `src/app/[locale]/layout.tsx`（server component）：
  - `generateStaticParams` 输出 `['zh','en']`；
  - `setRequestLocale(locale)` + `NextIntlClientProvider`（messages 由 `getRequestConfig` 注入）；
  - `<html lang={locale}><body>…<AuthProvider><main/>…<TabNav/></AuthProvider></body></html>`。
- 所有现有页面 `src/app/*.tsx`（13 个 page）迁移到 `src/app/[locale]/`（保留各自 `"use client"`）。
- 新增 `src/middleware.ts`：`createMiddleware(routing)` 处理 locale 前缀；`matcher` 排除 `/api`、`/_next`、静态资源、带 `.` 的文件。
- `src/next.config.mjs`：包裹 `next-intl` 插件（`createNextIntlPlugin('./src/i18n/request.ts')`）。
- 新建 `src/i18n/routing.ts`（`defineRouting`：`locales:['zh','en']`, `defaultLocale:'zh'`）、`src/i18n/navigation.ts`（`createNavigation(routing)` → `Link`/`redirect`/`usePathname`/`useRouter` 的 locale 感知版）、`src/i18n/request.ts`（`getRequestConfig` 按 locale 加载 `messages/<locale>.json`）。

### 3.2 导航 locale 化（统一工具，避免逐文件 churn）

- 新增 `src/lib/locale.tsx`：`LocaleLink`（封装 next-intl 的 `Link`，自动加 locale 前缀）、`useLocaleNav()`（`push`/`replace` 自动加前缀）、`localeHref(href, locale)`。
- `src/components/TabNav.tsx`：12 个 tab 的 `href` 全部经 `LocaleLink`；标签用 `useTranslations('TabNav')` 翻译；隐藏逻辑改为比对 `/${locale}/login`。
- `src/components/AuthGate.tsx`：未登录 `replace('/${locale}/login')`。
- 各处 `router.push('/')` / `router.push('/course')` 等改为经 `useLocaleNav().push(...)`（传入相对路径）。

### 3.3 文案抽取

- `src/messages/zh.json`：现有中文 UI 文案（默认，等同于现状）。
- `src/messages/en.json`：对应英文翻译。
- 组件内 `useTranslations('Namespace')` + `t('key')` 替换硬编码中文；命名空间按页面/组件划分：`Common / Home / Login / Plan / Parent / Practice / Rewards / Chat / Speech / Scan / PictureBook / Course / WordCards / Report / TabNav / Components`。
- 翻译顺序（按 CJK 密度优先级）：`parent`(84) → `page`(45) → `plan`(31) → `chat`(27) → `word-cards`(25) → `rewards`(23) → `speech`(23) → `picture-book`(21) → `practice`(21) → `parent-report`(19) → `scan`(17) → `course` → `login`(已是英文)。

## 6. 测试计划（硬约束 #6）

### 单元测试（纯逻辑模块）

- `messages` 键一致性测试：`zh.json` 与 `en.json` 顶层及嵌套键集合**完全一致**（防止漏译/错键导致 `t()` 回退或崩溃）；用递归键收集纯函数（可单测）。
- `localeHref(href, locale)` 工具单测：相对路径加前缀、已带 locale 不重复加、绝对/http 链接透传。

### BDD/E2E 用户旅程（待服务栈：`next build`+`next start` 沙箱被 safe-delete 阻断）

- 默认中文：游客访问 `/` → 重定向 `/zh` → 看到中文 chrome（如 TabNav「首页」）。
- 切换英文：用户在语言选择器切换 en → 页面 chrome 变英文（如 TabNav「Home」）→ 刷新后仍英文（cookie 持久化）。
- 导航保前缀：在 `/zh/...` 点 TabNav 跳转到 `/zh/...`。

## 8. 风险点

- **路由重构高风险（已与用户确认 next-intl 改路由）**：所有页面迁移 + 中间件 + 根 layout 删除；`next build` 在沙箱被 safe-delete 阻断**无法本地验证**，依赖 CI 真实环境；须严格按 next-intl v3 App Router 文档实现（`setRequestLocale` + `createNextIntlPlugin` + `defineRouting`）。
- **SPA 内存 auth**：next-intl 中间件重定向仅首发未登录落地触发（此时无 token），客户端软导航不丢 token；硬刷新重置 token 为既有行为，非回归。
- **翻译覆盖**：~340 处中文 chrome，`parent/home/plan` 最重；需逐文件抽取，避免遗漏导致中英混排。
- **`npm install next-intl` 需网络**：若沙箱无网络则阻塞，需反馈用户（已启动后台安装）。
