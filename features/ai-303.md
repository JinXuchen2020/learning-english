# AI-303 — 口语评测接口 `POST /api/ai/speech/evaluate`

> 状态: in-progress | 栈: node-ts (NestJS 10 + TypeORM) | 分支: feat/ai-303
> 依赖: AI-302(前端录音组件产出 audio+时长), AI-106(retry/降级 provider 调用层) | 前置链: feat/ai-302
> 下游: AI-304(STT 转写) / AI-305(评分策略: Azure 音素级 + 相似度兜底) / AI-306(评分反馈+落库) / AI-307(`/speech` 页消费本接口)

## 1. 目标

为 M3「AI 每日口语训练」交付**评测入口**：新增 `POST /api/ai/speech/evaluate`，用 multer 接收
前端 `SpeechRecorder`(AI-302) 产出的录音文件 + `wordId`/`sentenceId`（二选一或直传 `referenceText`），
完成**上传校验（大小/格式/时长）**与**评分返回**。校验层是 AI-303 的核心；实际转写/音素级打分的
增强在 AI-304/305，本 feature 仅通过 `AiProvider.assessPronunciation`（AI-101 已定义契约，Mock 已返回
确定性 `ScoreResult`）拿到评分，**不重复实现评分算法、不落库**（落库属 AI-306）。

## 2. 接口契约

### 路由
- `POST /api/ai/speech/evaluate`（`@Controller('ai/speech')` + 全局前缀 `api`）
- `Content-Type: multipart/form-data`
- 文件字段：`audio`（单文件，multer `FileInterceptor('audio')`）
- 文本字段（form field）：`wordId?` / `sentenceId?` / `referenceText?` / `durationMs?`

### 请求
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `audio` | file | 是 | 录音二进制；来自 `SpeechRecorder`（webm/opus 或 iOS `audio/mp4`） |
| `wordId` | string | 三选一 | 单词 id → 解析 `Word.text` 作参考文本 |
| `sentenceId` | string | 三选一 | 句子 id（句库 AI-309 落地；当前暂无 Sentence 实体 → 返回 400 `SENTENCE_SCORING_NOT_READY`） |
| `referenceText` | string | 三选一 | 直传参考文本（句子模式 / E2E 便利） |
| `durationMs` | number | 否 | 客户端上报录音时长（来自 `SpeechRecorder.durationMs`）；超过上限 → 400 `DURATION_EXCEEDED` |

### 响应 `ScoreResult`（与 AI-101 契约一致）
```jsonc
{ "score": 88, "readableText": "three", "weakPhonemes": ["θ","v"],
  "feedback": "…", "mascotExpr": "encourage" }
```
`score ∈ [0,100]`，60 为默认通过线（AI-306 使用）。

### 错误码（HTTP status + `code`）
| 场景 | status | code |
| --- | --- | --- |
| 缺 `audio` 文件 | 400 | `NO_AUDIO` |
| `audio` 为空（size=0） | 400 | `EMPTY_AUDIO` |
| `audio` 超 `MAX_AUDIO_BYTES`(5MB) | 413 | `AUDIO_TOO_LARGE` |
| `audio` MIME 不在白名单 | 415 | `UNSUPPORTED_AUDIO_TYPE` |
| `durationMs` 超 `MAX_DURATION_MS`(15s) | 400 | `DURATION_EXCEEDED` |
| `wordId`/`sentenceId`/`referenceText` 全部缺失 | 400 | `MISSING_REFERENCE` |
| `wordId` 查不到对应 Word | 404 | `WORD_NOT_FOUND` |
| 传 `sentenceId`（句库未落地） | 400 | `SENTENCE_SCORING_NOT_READY` |
| provider 调用失败（非 4xx 业务错） | 500 | 透传 provider 异常 |

## 3. 纯逻辑层 `speech-evaluate.validation.ts`（node 可测，对齐 AI-302 lib 模式）
- `ALLOWED_AUDIO_MIME: ReadonlySet<string>` = `{'audio/webm','audio/mp4','audio/wav','audio/mpeg','audio/ogg','audio/x-matroska','audio/x-wav'}`
  （覆盖 `SpeechRecorder` 产出 webm/opus、iOS `audio/mp4`，及常见 wav/mp3/ogg）。
- `MAX_AUDIO_BYTES = 5 * 1024 * 1024`（5MB）；`MAX_DURATION_MS = 15_000`（15s，留出 10s 默认录制余量）。
- `SpeechEvaluateError extends Error`：`{ status: number; code: string }`（**普通 Error，不继承 HttpException**，
  便于 node 单测；由 controller 翻译为 `HttpException`）。
- `validateSpeechUpload(input: { size: number; mimeType: string; durationMs?: number }, opts?): void`
  — 顺序校验：size≤0→`EMPTY_AUDIO`(400)；size>`maxBytes`→`AUDIO_TOO_LARGE`(413)；
  `!ALLOWED_AUDIO_MIME.has(mimeType)`→`UNSUPPORTED_AUDIO_TYPE`(415)；
  `durationMs!=null && durationMs>maxDurationMs`→`DURATION_EXCEEDED`(400)。**纯函数，无 Nest 依赖**。

## 4. 服务与控制器
- `AiSpeechEvaluatorService.evaluate(cmd: { file: UploadedAudioFile; dto: EvaluateSpeechDto }): Promise<ScoreResult>`
  1. 若 `!file || !file.buffer` → 抛 `SpeechEvaluateError(400,'NO_AUDIO')`。
  2. `validateSpeechUpload({size:file.size, mimeType:file.mimetype, durationMs:dto.durationMs})`。
  3. `resolveReferenceText`：`dto.referenceText` 直用 → 否则 `dto.wordId` 查 `WordRepository` 取 `text`
     （查不到→404 `WORD_NOT_FOUND`）→ 否则 `dto.sentenceId` 存在→400 `SENTENCE_SCORING_NOT_READY`
     → 否则 400 `MISSING_REFERENCE`。
  4. `provider.assessPronunciation({data:file.buffer, mimeType:file.mimetype}, ref, {passLine:60})` → 返回。
  - **不落库**（落库属 AI-306）；不引入 `AiSpeechAttemptService` 依赖，严守边界。
  - `UploadedAudioFile` 自定义接口（buffer/mimetype/size/originalname），避免依赖 `@types/multer`（仓内未装）。
- `AiController`（注册进 `AiModule`，`@Global`）：
  - `@Post('evaluate') @UseInterceptors(FileInterceptor('audio',{limits:{fileSize:10*1024*1024}}))`
    — multer 硬上限 10MB 防内存爆；精确 5MB→413 在 service 判定。
  - 方法 `evaluate(@UploadedFile() file, @Body() dto)`：`try { return await evaluator.evaluate({file,dto}) }`
    `catch(e){ if(e instanceof SpeechEvaluateError) throw new HttpException({code:e.code,message:e.message}, e.status); throw e }`。

## 5. 验收标准
- [ ] 合法音频（webm/mp4，≤5MB，≤15s）+ `wordId` → 200 且返回 `ScoreResult`（Mock 下 score=88）。
- [ ] 缺 `audio` → 400 `NO_AUDIO`；空文件 → 400 `EMPTY_AUDIO`。
- [ ] 超 5MB → 413 `AUDIO_TOO_LARGE`；错误 MIME → 415 `UNSUPPORTED_AUDIO_TYPE`；超 15s → 400 `DURATION_EXCEEDED`。
- [ ] `wordId` 不存在 → 404 `WORD_NOT_FOUND`；仅传 `sentenceId` → 400 `SENTENCE_SCORING_NOT_READY`。
- [ ] `tsc --noEmit`(server) 0 错误；`nest build` 通过；`jest` 全绿；覆盖率 90/70 基线不退化。
- [ ] pre-commit 质量门强执通过。

## 6. 风险点
- **E2E 豁免（约束 #6）**：纯后端 API 端点，无前端 UI（前端消费者是 AI-307 `/speech` 页）。按本项目
  「不为纯后端 API 写 BDD」铁律豁免 BDD/E2E，验收（合法→评分 / 超大空→4xx）由单元测全覆盖；
  完整「录→提交→评」用户旅程在 AI-307 的 `/speech` E2E 中经 client-side 导航覆盖。与 AI-301 纯后端豁免同口径。
- **无 Sentence 实体**：句库 AI-309 才建；`sentenceId` 当前显式返回 400 而非静默失败，避免误导。
- **时长校验信任客户端**：服务端不解析音频元数据（无 ffmpeg），`durationMs` 由客户端上报；
  真实服务端解析留作后续增强（标注于 §6，不越界）。
- **不落库**：评分持久化在 AI-306（消费 AI-301 `ai_speech_attempts` 实体），本 feature 不引入该依赖。
