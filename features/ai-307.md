# AI-307 — `/speech` 页面 · 跟读卡片（听→录→评→反馈→得星）

> Feature: `feat/ai-307` · 里程碑: M3（口语训练）· 优先级: P0
> 依赖: AI-302（`SpeechRecorder` 录音组件）、AI-303（`POST /api/ai/speech/evaluate`）、AI-306（`SpeechFeedback` 反馈结构）
> 下游: AI-308（口语任务联动 — 从 Home mic 任务进 `/speech` + 完成勾选/进度回写）、AI-602（难度自适应消费分数）
> 上游 AI-402（TTS 集成）**未落地** → 本 feature 用浏览器原生 Web Speech API 作朗读降级（详见 §5），不越界构建后端 TTS。

## 1. 目标

把 M3 口语链（AI-302 录 / AI-303 评 / AI-306 反馈）组装成**儿童可感知的跟读闭环页面**：
听单词 → 录音跟读 → 提交评分 → 看反馈（分数/弱音素/吉祥物表情）→ 通过得星 + 庆祝动画。

验收标准（来自 backlog）：
- 完整流程：听 → 录 → 评 → 反馈 → 得星；星级动画触发。
- 单词卡片 + 吉祥物朗读按钮 + 录音/重试/提交。
- 反馈正确展示 `score / passed / level / mascotExpr / weakPhonemes / feedback`。
- 通过线 60 分（与 AI-306 `PASS_LINE` 一致）驱动星级/鼓励动画。

## 2. 接口契约

### 后端（复用，无新增）
- `GET /words`（`src/lib/api.ts` 的 `getAllWords()`）→ `Word[]`（`id/text/phonics/meaning/illustration`），作跟读卡片数据源。
- `POST /api/ai/speech/evaluate`（`multipart/form-data`）：`audio` 文件 + 字段 `wordId | sentenceId | referenceText`（三选一参考文本）、`durationMs?`、`userId?`、`audioPath?`。
  - 返回 `SpeechFeedback`（AI-306）：`score / readableText / weakPhonemes / feedback / mascotExpr / passed / level`。
  - `MockProvider.assessPronunciation` 返回确定性 `score:88, weakPhonemes:['θ','v'], mascotExpr:'encourage'`（无 key 演示）。

### 前端（新增）
- `src/lib/types.ts`：新增 `SpeechLevel`、`SpeechFeedback`（与后端结构对齐）、`EvaluateSpeechResponse` 别名。
- `src/lib/speech.ts`（**纯逻辑层**，零/少依赖，node 可测）：
  - `mapBackendMascotExpr(expr): MascotExpression` — 后端表情 → 前端 `Mascot` 表情映射。
  - `isSpeechSynthesisSupported(synth?): boolean`。
  - `speakText(text, opts?): boolean` — 浏览器原生 TTS（Web Speech API），注入式 `synth`，无支持时安全 no-op。
- `src/lib/api.ts`：新增 `evaluateSpeech(file, opts): Promise<SpeechFeedback>`（构造 FormData、POST、解析、非 ok 抛 `ApiError`）。
- `src/app/speech/page.tsx`（**新页面**，client component + `AuthGate`）：跟读卡片组 UI + 状态机。
- `src/components/TabNav.tsx`：新增 `Speak` 标签 → `/speech`（供 E2E 客户端导航 + 用户可达）。

## 4. 验收标准（可验证）
- [ ] `/speech` 经 TabNav 可达；登录后展示 ≥1 张单词卡片（含 Listen 按钮）。
- [ ] 点击 Listen → 调用 `speechSynthesis`（无支持时不崩溃）。
- [ ] 录音（AI-302）→ 提交 → `evaluateSpeech` 返回 `SpeechFeedback` 并渲染分数/等级/映射后的吉祥物表情/弱音素。
- [ ] 通过（score≥60）→ 得星 + 庆祝动画（Mascot `celebrating` + 星 pop）。
- [ ] 未通过 → 鼓励文案 + `encouraging` 表情，不得星。
- [ ] 录音组件错误（权限/不支持）由 `SpeechRecorder` 自身友好提示，不阻塞页面。

## 5. 风险点与缓解

### 5.1 MascotExpression 契约错位（高，必须处理）
后端 `ai-provider.interface.ts`：`MascotExpression = 'happy' | 'encourage' | 'thinking' | 'cheer'`
前端 `src/lib/types.ts` + `Mascot.tsx`：`MascotExpression = 'happy' | 'thinking' | 'celebrating' | 'encouraging'`
→ 后端 `mascotExpr`（如 `'encourage'`/`'cheer'`）**不是**前端 `Mascot` 合法值，直接透传会 TS 报错且渲染 fallback。
**缓解**：`mapBackendMascotExpr` 显式映射 `cheer→celebrating / encourage→encouraging / happy→happy / thinking→thinking`，未知/缺省 → `happy`。该映射在 Phase 2 全栈契约对齐中验证。

### 5.2 TTS（AI-402）未落地
本 feature 需要"吉祥物朗读按钮"。AI-402（后端狐狸音色 TTS）仍在 backlog。**缓解**：用浏览器原生 `window.speechSynthesis`（Web Speech API）作前端朗读，零后端依赖、可离线演示；在文档与设计明确标注"生产狐狸音色待 AI-402 接入替换"。不构建 `/ai/tts` 端点（越界）。

### 5.3 麦克风在 E2E 不可用
Playwright/headless 无真实麦克风。**缓解**：E2E 用 `page.addInitScript` 注入假 `getUserMedia` + 假 `MediaRecorder`（立即产出 1KB `audio/webm` blob），驱动真实 `SpeechRecorder` 组件走到 `recorded` 态；同时 `page.route` 拦截 `POST /api/ai/speech/evaluate` 返回确定性 `SpeechFeedback`（不依赖后端 ML/鉴权），保证用户旅程（听→录→评→反馈→得星）稳定可验。

### 5.4 路由结构变更（TabNav 新增 Speak）
新增底部导航项属 UI 增强，明确由"建 /speech 页"隐含，非破坏性（不删/不改既有路由）。遵循既有 `E2E_BROWSER_CHANNEL` + AuthGate 客户端导航约定（页面对象 `open()` 经 `nav a[href="/speech"]` 点击，不用 `page.goto` 目标路由以免清空内存 token）。
