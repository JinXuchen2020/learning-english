# AI-205 — 内置模板计划（3 档静态周计划 + 用户可选模板）

> 状态: in-progress | 栈: node-ts (NestJS + TypeORM) | 分支: feat/ai-205 | 依赖: AI-201 (done), AI-204 (done, 最小兜底模板)

## 1. 目标
把 AI-204 的「单一最小兜底模板」升级为 **3 套按 `dailyMinutes` 档位的静态周计划**，并开放「用户主动选模板、不走 LLM」的生成路径。让应用在**无 LLM key / key 不可用**时，仍能产出结构合规、可渲染、且随每日时长自适应的学习计划（降级安全网 + 主动选模板双通道）。

用户价值：无网络/无 key 环境下，家长与孩子也能直接拿到一份合理计划；每日时长越长，复习密度越高。

## 2. 接口契约
### 后端
- 复用 `POST /api/ai/plan/generate`（`server/src/plan/plan.controller.ts`）。
- `GeneratePlanDto` 新增可选字段：
  - `useTemplate?: boolean`（`@IsOptional() @IsBoolean()`）—— 为 `true` 时跳过 LLM，直接返回内置模板计划（model:`'template'`, `degraded:false`）。
- 响应仍为 `GeneratePlanResponse { plan, model?, degraded }`：
  - LLM 失败降级（AI-204）：`degraded:true, model:'template'`（行为不变）。
  - 用户主动选模板（AI-205）：`degraded:false, model:'template'`（无 LLM 依赖，非失败态）。
  - 前端可据 `model==='template'` 展示「模板计划」徽标。

### 模板档位（核心交付）
`dailyMinutes`（经 class-validator 约束为 [5,120] 整数）→ 档位：

| 档位 `PlanTier` | 触发 `dailyMinutes` | 每日 lesson 数 | 每日结构（type / skillType） |
|---|---|---|---|
| `short` 轻量 | ≤ 15 | 2 | 1 主课（当日主技能，随 vocab/listen/speak/write 循环）+ 1 口语(speak) |
| `standard` 标准 | 16–45 | 4 | 1 主课 + 2 复习(vocab,listen) + 1 口语(speak) |
| `extended` 强化 | ≥ 46 | 5 | 1 主课 + 3 复习(vocab,listen,write) + 1 口语(speak) |

- 主课 `skillType` 仍按 AI-203/AI-204 约定随四技能日循环交错（day.skillType）。
- 主题词融合首选兴趣 + 等级（沿用 `themeWord`），与 AI-204 一致。
- 不引用真实 `courseId/lessonId`（存在性校验随目录注入属 AI-206）。

## 3. 数据模型
无新增实体/表（AI-201 的 `study_plans` / `study_plan_days` 已落地，落库属 AI-206）。本 feature 仅改内存模板生成逻辑。

## 4. 验收标准
- [ ] `resolveTier(5|15)='short'`, `resolveTier(16|45)='standard'`, `resolveTier(46|120)='extended'`
- [ ] `buildFallbackPlan` 按 `dailyMinutes` 选档：short→每日 2 节、standard→4 节、extended→5 节
- [ ] 三档产出均通过 `validatePlan`（ok:true），可安全渲染
- [ ] `dto.useTemplate=true` 时 `generatePlan` 不调用 `AiProvider.chat`，直接返回 `model:'template', degraded:false`
- [ ] `dto.useTemplate` 缺省时行为不变（照常走 LLM + 重试 + 降级）
- [ ] `useTemplate` 非布尔被 class-validator 拦截（400）

## 5. 风险点
- 档位边界与前端表单（文档写 10/20/30min）不完全对齐 → 仅 10→short、20/30→standard 经 UI 可达，extended 需更长时长；属后端能力覆盖全 [5,120] 范围，可接受。
- 不能破坏 AI-204 既有降级路径与单测（standard 档即 AI-204 原 4 节结构，向后兼容）。
