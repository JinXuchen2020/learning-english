# AI-408 — 对话星标与鼓励（完成 N 轮得星 + 吉祥物庆祝 + Home 展示）

> 依赖：AI-407（`/chat` 会话 UI）、AI-401（`ai_chat_sessions` 实体，含 `stars` 列）、AI-403（`POST /api/ai/chat/messages`）。
> 类型：**前后端协同功能**，按项目测试约定（约束 #6）前端部分需 **BDD/E2E**（用户可感知端到端旅程），后端纯逻辑（星标计算/聚合）需 **单元测试**。

## 1. 目标
为 5-10 岁孩子在「和狐狸练英语对话」时提供即时正反馈闭环：
- **完成 N 轮对话得一颗星**：后端按本会话已完成轮数（用户发言条数）计算星数，跨过阈值（默认 8 轮）时 `starAwarded=true`，并把累计星数落库 `ai_chat_sessions.stars`。
- **会话内即时庆祝**：前端收到 `starAwarded` 时弹出吉祥物庆祝横幅（`Mascot` celebrating），4 秒后自动消失，可手动关闭；头部常驻「本会话累计星数」徽标。
- **Home 聚合展示**：`/`（Home）问候横幅独立拉取该用户所有会话累计星数，渲染「聊天星星」卡（与练习星相互独立）。

## 2. 前后端契约

### 2.1 `POST /api/ai/chat/messages`（AI-403 扩展，AI-408 增量）
请求体不变：`{ text, sessionId?, sceneId?, userId? }`。
响应体新增三字段（旧字段 `sessionId/messageId/replyText/ttsUrl` 不变）：

```
}
```

### 2.2 `GET /api/ai/chat/stars?userId=`（AI-408 新增）
```

→ 返回 { stars }   // 该用户所有会话累计星数
```

### 2.3 前端类型（`src/lib/types.ts`）

## 3. 星标计算（单一数据源：`server/src/chat/chat-stars.ts`）
```ts
export const CHAT_STAR_ROUNDS = 8;
export function computeStars(rounds: number, prevStars: number): StarAward {
  const safeRounds = Math.max(0, Math.floor(rounds));
  const stars = Math.floor(safeRounds / CHAT_STAR_ROUNDS);
  const starAwarded = stars > prevStars;          // 用「星数是否增加」判定，避免续聊/重复 send 双发星
  const remainder = safeRounds % CHAT_STAR_ROUNDS;
  const starsUntilNext = remainder === 0 ? CHAT_STAR_ROUNDS : CHAT_STAR_ROUNDS - remainder;
  return { stars, starAwarded, starsUntilNext };
}
```
- `rounds` 由 `ChatService.sendMessage` 在 TTS 合成后用 `messageRepo.count({where:{sessionId, role:'user'}})` 得到（本会话用户发言条数 = 已完成轮数）。
- `prevStars = session.stars`（落库值）；当 `starAwarded` 为真，把新 `stars` `save()` 回 `ai_chat_sessions`。
- 用 `stars > prevStars` 而非 `rounds % 8 === 0`：续聊恢复或同轮重复调用不会重复发星；纯函数便于单测覆盖边界（0/7/8/9/15/16、负/浮点安全、`prevStars` 已领先等）。

## 4. 前端 UI 与 data-component 钩子（供 E2E 定位）
- **`/chat`（`src/app/chat/page.tsx` → `ChatInner`）**
  - 头部徽标 `ChatStarCount[data-component]`：仅 `sessionStars>0` 渲染，显示本会话累计星数。
  - 庆祝横幅 `ChatStarCelebration[data-component][data-stars]`：`celebration != null` 时渲染，`Mascot expression="celebrating"`，「🎉 You earned a star!」+「{stars} ⭐ so far」+ 关闭按钮 `data-action="dismiss-celebration"`；`useEffect` 在 `celebration` 变化后 4s 自动置 `null`。

  - `load()` 内 `await api.getChatStars(user?.id)`（与主数据 `Promise.all` 解耦，独立 `try/catch`，失败不影响课程/任务/进度）。

## 5. 边界与降级
- `sendMessage` 内部 `messageRepo.count` 异常：星标计算回退为 `computeStars(0, session.stars)` → `starAwarded=false`，不阻断主对话链路（`stars/starAwarded/starsUntilNext` 仍随响应返回，值安全）。
- `getChatStars` 失败：Home `chatStars` 保持 0，不渲染 `ChatStars` 卡，主数据照常展示。
- 阈值 `CHAT_STAR_ROUNDS=8` 为单一常量，调参只改 `chat-stars.ts` 一处。
- `ai_chat_sessions.stars` 列由 AI-401 建表时预留（默认 0，注释「AI-408 写入」），**无 DB migration**。

## 6. 越界声明
- 会话历史列表与续聊（AI-409）不在本 feature；`sessionId` 仍透传复用。
- 跟读评测星（AI-307/AI-408 口语星）与对话星相互独立，Home 上分别展示（`progress.totalStars` vs `ChatStars`）。
