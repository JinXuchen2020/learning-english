# AI-801 — 学习计划 → 课程生成（Plan-to-Course Generation）

> 状态: todo | 栈: node-ts (NestJS 10 + TypeORM + better-sqlite3 / Next.js 14) | 分支: feat/ai-801
> 来源: 用户决策（2026-08-16）— 路径 B：定制学习计划后，按计划的主题/兴趣/等级**真正生成对应 Course + Lesson + Word**，而非仅引用静态种子课程。

## 1. 目标

当前 `PlanService` 生成/保存/应用计划时**从不创建课程**（`CoursesService` 仅有 `findAll`/`findOne` 只读），且 `generatePlan` 把课程目录 `catalog` 硬编码为 `undefined`，计划与课程是两条平行线。
本 feature 在"定制计划"后提供**一键生成配套课程**：以计划的主题/兴趣/等级/天数推导出一门（或多门）`Course`，每计划日对应一节 `Lesson`，每节由 AI 产出若干 `Word`（英文 + 音标 + 中文 + 例句 + 测验选项），落库后可在 `/courses` 正常学习。价值：让"定制计划"产生可追溯、可学习的真实课程内容，而非孤立排期。

> 与 AI-203 已设计但断线的 `curriculumCatalog` 引用机制解耦：本 feature **生成**课程（写 Course/Lesson/Word），不强依赖种子目录。后续若需计划反向引用这些课程，可另开 AI-802 做 plan→courseId 回填。

## 2. 接口契约

### 后端（NestJS，`@Controller('ai/plan')`，全局前缀 `/api`）

- `POST /api/ai/plan/:id/generate-courses`
  - 入参：路径 `id`（已保存计划 UUID）；body 可选 `{ wordsPerLesson?: number(3..8, 默认 5) }`。
  - 行为：
    1. 加载 `StudyPlan`（含 `days`），不存在 → 404 `{code:'PLAN_NOT_FOUND'}`。
    2. 由计划推导课程规格（标题来自 week theme / interests / level；lesson 数 = 计划天数；每节标题来自当日 lessons/theme）。
    3. 调 `AiProvider.chat` 一次性产出结构化课程 JSON（见 §3 结构），`temperature:0.5, maxTokens:4096`。
    4. `validateCoursePlan` 结构校验 → 失败自动重试（≤3 次，附 `retryNote`）→ 仍失败降级内置模板课程（`degraded:true`）。
    5. 经 `CoursesService.createCourseFromPlan(spec)` 落库（Course + Lessons + Words，事务/级联）。
  - 响应：`{ courseId: string; title: string; lessonCount: number; wordCount: number; degraded: boolean; model: string }`
  - 校验：非法 `wordsPerLesson` → 400；计划不存在 → 404。
- 复用 `PlanService` 内已有的 `AiProvider`（`AiModule` `@Global()` 注入），无需重复 import。

### 前端（Next.js，`src/lib/api.ts` + `/plan` 页）

- `generateCoursesForPlan(id, dto?)` → `POST /api/ai/plan/:id/generate-courses`
- 类型 `GenerateCoursesResponse` / `GenerateCoursesDto` 镜像进 `src/lib/types.ts`。
- `/plan` 页 `PlanPreview` 在「应用此计划」成功后展示「生成配套课程」按钮；点击调用接口，成功后 `router.push('/courses')` 查看新课。失败显示错误提示。

## 3. 数据模型与产出结构

**生成阶段 AI 产出（经 `validateCoursePlan` 校验）：**
```json
{
  "course": { "title": "太空探险英语 · A1", "description": "…", "icon": "rocket", "color": "#6C5CE7" },
  "lessons": [
    {
      "title": "Star Words",
      "estimatedMinutes": 8,
      "words": [
        { "text": "star", "phonics": "stɑːr", "meaning": "星星",
          "example": "The star is bright.", "exampleTrans": "星星很亮。",
          "options": ["star","sun","moon","sky"], "correctIndex": 0 }
      ]
    }
  ]
}
```
- `Word.options` 为长度 2–4 的字符串数组（含正确项），`correctIndex` 指向正确项；`phonics` 为英文音标串；`illustration`/`category`/`color` 落库时由后端补默认（`illustration:null`，`category` 取课程主题，`color` 取课程 color 或 null）。
- `simple-array` 列 `options` 由后端逗号拼接存储；`correctIndex` 为 `@Column()` 必填 number。

**落库实体（新增写路径，不改现有读路径）：**
- `Course`（title/description/icon/color/sortOrder）
- `Lesson`（title/sortOrder/estimatedMinutes/courseId）
- `Word`（text/phonics/meaning/illustration:null/options/correctIndex/sortOrder/category/color/lessonId）

## 4. 实现要点

- **`CoursesModule`**：`forFeature` 增加 `Word`；**导出 `CoursesService`**（现未导出，PlanModule 需注入）。
- **`CoursesService.createCourseFromPlan(spec)`**：纯持久化，使用 `coursesRepo`/`lessonsRepo`/`wordRepo` 顺序 save（Lesson 经 `courseId` 关联，Word 经 `lessonId` 关联；或开启事务保证原子性）。返回创建后的 `courseId` 与计数。
- **`PlanService.generateCoursesForPlan(id, wordsPerLesson)`**：推导规格 → AI 调用 → 校验/重试/降级 → 调 `coursesService.createCourseFromPlan` → 返回响应。注入 `CoursesService`（PlanModule import CoursesModule）。
- **提示词**：新建 `courses-from-plan.prompt.ts`（双语儿科友好，要求输出合规 JSON、单词适合 `level`/年龄、内容安全红线），参考 `plan-agent.prompt.ts` 风格。
- **Schema 校验**：新建 `courses-from-plan.schema.ts`（`validateCoursePlan`，类似 `plan-schema.ts`）。
- **模板降级**：新建 `courses-from-plan.template.ts`（`buildFallbackCoursePlan(plan, wordsPerLesson)`），产出主题化通用课程（icon=`book`，color 取调色板）。
- **`PlanController`**：新增 `POST :id/generate-courses` 路由。

## 5. 验收标准

- 对一个已保存计划调用 `generate-courses`，返回 200 且 `courseId` 非空；`/api/courses/:courseId` 可查到该课程、lesson 数 = 计划天数、每节含 `wordsPerLesson` 个单词。
- 单词字段合法：`text/phonics/meaning` 非空、`options` 长度≥2、`correctIndex` 在范围内、`lessonId` 正确关联。
- AI 不可达 / JSON 不合规时降级模板课程仍返回 200 且 `degraded:true`，课程可正常落库与查询。
- 计划不存在 → 404。
- 前端 `/plan` 应用计划后出现「生成配套课程」按钮，点击后跳转 `/courses` 可见新课。
- 单测覆盖：`validateCoursePlan` 合法/非法样例、`createCourseFromPlan` 落库计数、`generateCoursesForPlan` 降级路径。
- 提交前 `tsc --noEmit`（后端）+ `next build`（前端）通过。
