# AI-605 — AI 复习提醒（间隔重复 / Spaced Repetition）

> 状态: done | 栈: node-ts (NestJS + Next.js) | 分支: feat/ai-605 | 来源: docs/ai-integration.md M6

## 1. 目标
基于遗忘曲线（间隔重复，SM-2 简化版）为每个孩子跟踪每个单词的「下一次复习到期日」；当单词临近/已经遗忘（到期）时，自动进入「当日任务」并醒目提示，孩子点一下即可进入练习复习。复习节奏（间隔阶梯）可配置。

用户价值：把「该复习哪个词、什么时候复习」从家长/孩子凭感觉，变成系统按记忆规律自动推送，减少遗忘、提升 retention。

## 2. 接口契约

### 后端（ProgressModule，均 `@UseGuards(JwtAuthGuard)`，userId 取自 token）
- `GET /progress/review/due?date=YYYY-MM-DD`（默认今天）→ `DueReview[]`
  - 返回 `dueDate <= date` 且 `dueDate` 非空的单词进度（leftJoin Word 取 text/meaning），按 `dueDate` 升序。
  - `DueReview { wordId, wordText, meaning, dueDate(ISO), reviewPriority, difficulty, intervalDays }`
- `GET /progress/review/settings` → `{ enabled: true, intervals: number[] }`
  - `intervals` 即当前生效的间隔阶梯（天），来自 `REVIEW_INTERVALS` 环境变量，缺省 `[1,2,4,7,15,30,60]`。
- `POST /progress/review/schedule` body `{ wordId, dueDate(ISO) }` → 手动调整某词的下一次复习时间（家长/老师可把某词推到明天或提前），返回更新后的进度摘要。
  - 仅能调整自己 userId 下的词；词不存在返回 404。

### 前端
- `api.getDueReviews(userId, date?)` → `DueReview[]`（`/progress/review/due`）
- `api.getReviewSettings(userId)` → `ReviewSettings`（`/progress/review/settings`）
- Home `page.tsx`：主 `load()` 并行拉 `getDueReviews(user.id)`；到期后：
  - 注入「今日任务」列表（`getDailyTasks` 服务端现场附加复习项，icon=`review`，渲染为 `/practice?focusWord=X` 链接）→ 满足「过期单词进入当日任务」。
  - 另显式渲染一张「今日复习」卡（`data-component="ReviewReminderCard"`）汇总条数 + 去复习入口。

## 3. 数据模型
- `word_progress` 表新增列（better-sqlite3 `synchronize:true` 自动建列）：
  - `intervalDays INTEGER default 0` — 当前间隔天数
  - `easeFactor FLOAT default 2.5` — SM-2 易化因子
  - `reviewCount INTEGER default 0` — 连续正确次数（间隔阶梯档位）
  - `dueDate DATETIME null` — 下次复习到期日（null=尚未纳入复习计划）
- 算法（`review-schedule.util.ts`，纯函数，可单测）：
  - 正确：`reviewCount+1`；`easeFactor=min(3.0, prev+0.1)`；`intervalDays=intervals[min(reviewCount-1, len-1)]`；`dueDate=now+intervalDays天`
  - 错误：`reviewCount=0`；`easeFactor=max(1.3, prev-0.2)`；`intervalDays=intervals[0]`；`dueDate=now+intervalDays天`
  - `recordWordAttempt` 在 save 前调用 `computeNextReview` 写入上述四列。

- [ ] `GET /progress/review/due` 返回 `dueDate<=今天` 的单词；无到期词返回 `[]`
- [ ] 到期单词出现在 Home「今日任务」中（复习链接，点开进 `/practice?focusWord=X`）
- [ ] Home 显式「今日复习」卡在有到期词时出现，列出条数
- [ ] 复习间隔阶梯可经 `REVIEW_INTERVALS` 环境变量配置，`/review/settings` 返回当前值
- [ ] 单元单测覆盖 `computeNextReview` 全部分支；E2E 覆盖「播种到期词→看到复习卡/任务→点击复习→练习页显示该词」

## 5. 风险点
- **交叉模块依赖**：`getDailyTasks` 需调 `ProgressService.getDueReviews` → `TasksModule` import `ProgressModule`（单向，无环；AiModule 已 `@Global`）。`tasks.service.spec` 需补 `ProgressService` mock。
- **`dueDate` 注入每日任务**：采用「服务端 `getDailyTasks` 现场附加（不落库）」而非写 `daily_tasks` 行，避免重复行/完成态耦合；复习项是 Link（非 complete 按钮）。
- **E2E 需到期词**：公开 API 只能生成「未来到期」词；用 `POST /progress/review/schedule` 把 dueDate 设为昨天，使词「到期」可被 E2E 稳定断言（该接口本身也是合法功能：家长可手动调整复习时间）。
- **Node/端口坑**：后端须 Node 20；E2E 前清遗留 server（`netstat`+`taskkill`），后端 `AI_PROVIDER=mock`。
