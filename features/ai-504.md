# AI-504 · Home「今日 AI 小结」卡片

> 模块：M5「AI 错题与进度报告」· 阶段：feature-builder（Craft）
> 依赖：AI-502（`POST /api/ai/report/daily` 接口 + `ai_reports` 表）、AI-503（ReportAgent 提示精炼）
> 分支：`feat/ai-504`（基于 `feat/ai-503`）

## 1. 目标 / 范围

在 Home（`src/app/page.tsx`）顶部新增**「今日 AI 小结」卡片**，消费 AI-502 的
`POST /api/ai/report/daily`，以吉祥物气泡形式展示当日 AI 报告：

- **摘要气泡**：`summaryText`（小狐口吻，儿童友好）
- **弱项词**：`weakWords[]` 以 chip 展示（AI-503 保证来自真实错题）
- **明日建议**：`suggestionText`
- **吉祥物表情**：`mascotExpr`（后端枚举 `happy|encourage|thinking|cheer`）经既有
  `mapBackendMascotExpr`（`src/lib/speech.ts`）映射到前端 `Mascot` 枚举
  （`happy|thinking|celebrating|encouraging`），**复用不重造**
- **展开详情**：点击「查看详情」展示 `date` + 默认报告提示（`isDefault`）
- **无报告 / 拉取失败**：显示小狐 `thinking` +「生成今日小结」按钮，点击重试

**纯前端消费层**：不新增后端接口（backlog 约束）；后端契约由 AI-502 定义、提示由 AI-503 精炼。

## 2. 数据契约（与后端 `DailyReportResponse` 对齐）

```ts
interface DailyReportResponse {
  id?: string;
  userId: string;
  date: string;                 // YYYY-MM-DD
  summaryText: string;          // 一句话小结（鼓励语气）
  weakWords: string[];          // 真实薄弱单词（无则 []）
  suggestionText: string;       // 明日建议
  isDefault: boolean;           // 无活动友好默认报告
  mascotExpr?: string;          // 后端枚举，渲染前 mapBackendMascotExpr
  createdAt?: string;           // ISO，读回时存在
  stats?: DailyReportStats | null;
}
```

`GET`/`POST` 封装：`getDailyReport(userId, date?)` → `request<DailyReportResponse>("/ai/report/daily", {method:"POST", body})`。
后端该路由**无 guard**（与 AI-502 一致），前端随内存 token 携带（与 `/ai/chat` 同口径）。

## 3. 实现要点

### 3.1 `src/lib/types.ts`
新增 `DailyReportResponse` + `DailyReportStats`（含 `weakWordCandidates`，与后端 `AI-502/503` 对齐）。

### 3.2 `src/lib/api.ts`
新增 `getDailyReport(userId, date?)`：`date` 缺省时只发 `{userId}`，否则 `{userId, date}`。
`request` 默认带 token、`ApiError` 在 4xx/5xx 抛出，本层不额外处理。

### 3.3 `src/app/page.tsx`
- `HomeContent` 增 `report / reportError` 状态；`load()` 末尾新增独立 `try`（与 chat stars 同口径，失败不影响主数据）：
  `user ? api.getDailyReport(user.id) : Promise.resolve(null)` → `setReport(...)`。
- 新增 `AiReportCard({ report, onRetry })` 组件（带 `data-component` 钩子）：
  - `report` 存在 → 吉祥物气泡 + summary（`AiReportSummary`）+ weakWords chips（`AiReportWeakWords`）+ suggestion（`AiReportSuggestion`）+ 展开按钮（`AiReportToggle`）/详情（`AiReportDetails`）。
  - `report` 为 `null`（拉取失败/无）→ 吉祥物 `thinking` + 文案 +「生成今日小结」按钮（`AiReportGenerateBtn`）→ `onRetry` 重新拉取。
- 插入位置：GreetingBanner 之后、PlanProgress 之前（顶部醒目）。
- 复用 `mapBackendMascotExpr(report.mascotExpr)` 得前端表情；`useState` 管展开态。

### 3.4 单元测试（Vitest，`src/lib/api.spec.ts`）
- `getDailyReport` 成功：`fetch` 被调用 `POST /api/ai/report/daily`，体含 `userId`，无 `date` 时体为 `{userId}`，有 `date` 时含 `date`；返回体映射为 `DailyReportResponse`。
- `getDailyReport` 400：`ApiError` 抛出且 `status===400`。
（`src/lib/api.ts` 属纯逻辑封装，按 feature-builder 前端单测铁律必测；E2E 覆盖 UI 行为。）
