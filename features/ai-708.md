# AI-708 — 前端响应式加固（移动端 P1/P2）

> 状态: in-progress | 栈: node-ts (Next.js 14 App Router + React 18, Tailwind) | 分支: feat/ai-708
> 来源: AI-707 收尾时评估发现的「前端自适应」剩余项（彼时仅完成可行性评估，未改代码）。P0（TabNav 12 栏溢出）已由 AI-707 的迷你程序式底栏（child 4 栏 / parent 3 栏）顺带消除；本 feature 补齐 P1 / P2。

## 1. 目标
让学习 App 在窄屏手机（320 / 375 / 390px）下排版可读、无横向溢出、浮动语言切换器不与页面顶栏内容重叠。用户价值：家长/孩子在真实手机上打开即 comfortably 可用，不出现字号过大顶破布局或语言药丸压住标题/徽标。

## 2. 接口契约
### 后端（如有）
- 无。纯前端 CSS / 组件布局改动，不涉及任何 API / DTO / 路由结构变更。

### 前端（如有）
- `src/app/globals.css`：`html` / `h1` / `h2` / `h3` 字号由写死 `px/rem` 改为 `clamp()` 流式排版（P1）。
- `src/components/LocaleSwitcher.tsx`：在窄屏下缩小自身占位（`text-[11px]`、`px-1.5 py-0.5`、`top-2 right-2`、`max-[360px]:scale-90`），降低与页面顶栏内容重叠的概率（P2-组件侧）。
- `src/app/[locale]/page.tsx`：首页问候横幅（`GreetingBanner`）在窄屏下由 `flex-row`（右侧 `ml-auto` 推 streak/star 徽标）改为 `flex-col`（徽标换行到问候语下方），使顶右区域在窄屏留空，避开固定的 `LocaleSwitcher`（P2-页面侧，已知碰撞点）。
- `src/app/[locale]/login/page.tsx`：外层容器补 `px-4`，使认证卡片不贴屏幕边缘，语言药丸浮于留白而非压在卡片右上角（P2-页面侧）。

## 3. 数据模型
- 无新增实体 / 表 / 迁移。

## 4. 验收标准
- [ ] 320 / 375 / 390px 视口下，`document.documentElement.scrollWidth <= window.innerWidth`（无横向溢出）。
- [ ] `html` 根字号在窄屏（≤400px）≤ 18px 且随视口流式收缩，在宽屏封顶 18px。
- [ ] `h1/h2/h3` 在窄屏流式收缩、宽屏封顶，不再写死单一尺寸。
- [ ] `LocaleSwitcher` 在 375px 下 `visible` 且自身占位 ≤ 64px 宽 / 32px 高，不遮挡首页问候横幅文字。
- [ ] 首页问候横幅在 ≤640px 为纵向堆叠（徽标在问候语下方），非右侧 `ml-auto` 贴顶。
- [ ] 登录卡片在窄屏不贴屏幕左右边缘。

## 5. 风险点
- **纯 CSS / 布局，零运行时逻辑**：无类型契约、无鉴权、无破坏性改动，回滚安全。
- **clamp 取值需保守**：下限不低于 15px（避免移动端过小），上限不超过既有 18px / 2rem（保持桌面现状），防止改坏桌面排版。
- **LocaleSwitcher 缩放在极窄屏（≤360px）用 `scale-90`**：仅视觉缩放，不改定位，避免引入新布局 bug。
- **不触及其他页面布局**：仅改首页问候横幅与登录容器两处已知碰撞点，其余页面经代码审阅确认顶栏内容左对齐、无顶右碰撞，不在本 feature 范围内（避免借机重构）。
