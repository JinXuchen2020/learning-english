# AI-809 · 表单体验与标签关联加固

> 里程碑：M13（UI 设计规范整改与无障碍加固） · 优先级 P2 · 分支 `feat/ai-809`（基于 `feat/ai-808`）

## 背景 / 动机
`ui-review-report.md` 与整体设计审查指出：家长设置页表单无法回车提交、输入框与 `<label>` 无程序化关联（仅靠视觉相邻），扫描页文件输入缺可访问名（依赖纯 CSS `file:` 伪元素），底部导航/语言切换/筛选按钮的切换状态未对读屏暴露。本 feature 收口这些表单与标签关联问题，对齐 WCAG 2.1 / WAI-ARIA 1.2。

## 改动清单

### 1. 家长设置 — 供应商配置表单 `ProviderConfigForm`（`src/app/[locale]/parent/settings/page.tsx:565`）
- 表单内容包进 `<form onSubmit>`（阻止默认提交 + 调 `handleSubmit`），支持**回车提交**。
- 输入框程序化关联 label：`provider-name` / `provider-type`(Select 触发按钮转发 `id`) / `provider-base-url` / `provider-api-key` / `provider-model` 全部补 `id` + 对应 `<label htmlFor>`。
- 原生校验：`name`/`baseUrl`/`model` 加 `required`；`apiKey` 仅新增时 `required={!editingId}`（编辑态可留空复用旧 key，保留既有 UX）。
- `model` 输入框补 `aria-describedby="provider-model-hint"` 关联提示文案。
- 保存按钮 `onClick` → `type="submit"`；取消按钮显式 `type="button"`（避免误触发表单提交）。

### 2. 家长设置 — 添加孩子表单 `AddChildForm`（`src/app/[locale]/parent/settings/page.tsx:1018`）
- 同样包 `<form onSubmit>`；`child-nickname`(仅 create 模式渲染) / `child-username` / `child-password` 补 `id` + `htmlFor` + `required`。
- 提交/取消按钮同上改为 `type="submit"` / `type="button"`；Tab 切换按钮本就 `type="button"`，不会误提交。

### 3. 扫描页文件输入可访问名（`src/app/[locale]/scan/page.tsx:123`）
- `ImageUploadInput` 补 `aria-label={t("imageUploadLabel")}`（`Input` 原语 `{...props}` 透传），不再依赖纯 CSS `file:` 伪元素作为唯一可访问名。
- 保留 `capture="environment"`（移动端强制摄像头为有意为之，符合扫码识词场景）。

### 4. 切换状态暴露（读屏）
- `TabNav.tsx`：底部主导航内联 `div` 加 `role="group"`（`aria-label` 复用 `mainNav`），把主标签组显式成组。
- `LocaleSwitcher.tsx`：容器 `div` 加 `role="group"`（语言切换是一组互斥 toggle，配合既有 `aria-pressed` 更完整）。`aria-pressed` 此前已就位。
- `word-cards/page.tsx:173`：状态筛选 `StatusTab` 按钮补 `aria-pressed={filter === s}`（筛选是 toggle，暴露按下态）。

### 5. i18n
- 新增 `Scan.imageUploadLabel`（en/zh），用于文件输入可访问名。

## 验证
- 前端 `tsc --noEmit` **0**。
- `src/messages/{en,zh}.json` 解析通过。
- 关键交互（结构与类型层验证）：
  - 设置表单：回车在任一文本输入可提交；空必填项触发原生校验气泡且 `handleSubmit` 不执行；编辑供应商时留空 apiKey 可正常保存。
  - 所有 `<input>`/`<Select>` 均有 `id` 且 label `htmlFor` 指向，程序化关联成立。
  - 文件输入读屏可报 `imageUploadLabel`。
  - TabNav/LocaleSwitcher 成组、语言/筛选按钮 `aria-pressed` 反映当前态。

## 范围与边界
- 未迁移 `parent/settings` 到 `Field` 原语（AI-807 引入的 `useId` 自动关联方案）：本 feature 按 spec 字面「补齐 htmlFor/id」，改动面小、风险低；`Field` 迁移可作为后续专项（与登录/word-cards 表单一起）。
- 能力勾选（capabilities）的 `<label>` 包裹 `<input type=checkbox>` 已自关联，外层 group label 维持现状，未改。

## 残余 / 后续

- `parent/settings` 表单可后续统一迁移至 `Field` 原语，进一步降低手写 id 漂移风险。
