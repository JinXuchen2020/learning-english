# AI-403 — 对话陪练聊天接口

> 状态: in-progress | 栈: node-ts (NestJS 10 + TypeORM，better-sqlite3/postgres 双驱动) | 分支: feat/ai-403

## 1. 目标
为 M4「AI 对话陪练」提供后端聊天接口 `POST /api/ai/chat/messages`：接收宝宝的发言，结合**会话历史 + 场景系统提示（狐狸人设）**调用 LLM 生成回复，落库 `ai_chat_sessions` / `ai_chat_messages`，并用 AI-402 的 TTS 能力产出狐狸音色朗读音频 URL，一并返回。这是 AI-407（`/chat` 前端页面）的数据底座。

用户价值：宝宝在场景里和狐狸吉祥物自然对话，说一句、狐狸回一句并开口朗读，逐步降低开口恐惧。

## 2. 接口契约
### 后端
- **路由**：`POST /api/ai/chat/messages`（全局前缀 `api`；不加 `JwtAuthGuard`，与本项目 AI 接口口径一致——鉴权推迟，userId 默认 `anonymous`）。
- **请求体 `ChatMessageDto`**（`application/json`，全局 `ValidationPipe` whitelist+transform+forbidNonWhitelisted）：
  - `text: string` **必填**，非空，≤ 2000 字符（宝宝发言）。
  - `sessionId?: string` 可选；提供则续聊既有会话（不存在 → 404 `CHAT_SESSION_NOT_FOUND`）；不提供则新建会话。
  - `sceneId?: string` 可选，≤ 64 字符；新建会话时写入 `ai_chat_sessions.sceneId`（自由对话可 null）；续聊时忽略（以会话本身为准）。
  - `userId?: string` 可选；不提供 → `'anonymous'`（与 AI-108 审计默认、评测 DTO 口径一致），写入会话 userId（varchar 引用，非硬外键）。
- **响应 `ChatSendResponse`**：
  - `sessionId: string` — 本次会话 id（新建或复用）。
  - `messageId: string` — 助手回复消息 id。
  - `replyText: string` — LLM 生成的狐狸回复正文。
  - `ttsUrl: string | null` — 狐狸朗读音频的可播放引用：provider 返回 `audioUrl` 则原样返回；返回 `audioBase64` 则归一为 `data:${mimeType};base64,...`；TTS 失败/无音频则为 `null`（前端退化为浏览器 TTS 或仅文本）。
- **错误**（业务错误 `ChatError` → controller 翻译为 `HttpException`）：
  - `404 CHAT_SESSION_NOT_FOUND` — 续聊时 sessionId 不存在。
  - `429 AI_RATE_LIMITED` — provider 限流（AI-106 code 1305 等）。
  - `502 AI_GENERATION_FAILED` — LLM 生成失败/超时（AI-106 网络/504/结构异常）。
  - `503 AI_UNAVAILABLE` — provider 访问/权限错误（缺 key 等）。
  - 入参非法 → `ValidationPipe` 自动 400。

### 前端（AI-407 消费，本 feature 不涉及页面）
前端 `/chat` 调用本接口，`ttsUrl` 直接喂 `<audio>` 自动播放；首轮不传 `sessionId`（新建），后续轮次携带返回的 `sessionId` 续聊。

## 3. 数据模型
复用 AI-401 已落地的实体，**无新表/字段变更**：
- `ai_chat_sessions`（AI-401）：新建会话时写 `userId` / `sceneId`（`stars` 默认 0，AI-408 写）。
- `ai_chat_messages`（AI-401）：每轮落两条——`user`（`text=dto.text`，`audioPath=null`）+ `assistant`（`text=replyText`，`audioPath=null`；**持久化音频留待 AI-407**，本 feature 仅在响应 `ttsUrl` 返回即时播放引用，避免 512 varchar 存超长 data URI）。
- 关联口径：均 varchar 引用（AI-301 审计记录口径），非硬外键。

## 4. 验收标准
- [ ] `POST /api/ai/chat/messages` 新建会话：返回 sessionId/messageId/replyText/ttsUrl，session 与两条 message 落库正确。
- [ ] 续聊：携带既有 sessionId 复用会话，历史消息进入 LLM 上下文，回复连贯。
- [ ] 非法入参（缺 text / text 空 / sceneId 超长 / 额外字段）被 `ValidationPipe` 拒（400）。
- [ ] 续聊不存在的 sessionId → 404 `CHAT_SESSION_NOT_FOUND`。
- [ ] TTS 归一化：audioUrl 透传、base64→data URI、空→null；TTS 失败不阻断文本回复（ttsUrl=null）。
- [ ] LLM 失败映射清晰错误码（429/502/503）；不抛未处理异常。
- [ ] 系统提示含狐狸人设 + 场景 framing（已知场景）+ 基线安全规则；未知/自由场景仅人设+安全。

## 5. 风险点
- **场景 Prompt 归属**：丰富的「场景包模板 + 内容安全双保险」属 AI-405/AI-406；本 feature 仅内置**基线**狐狸人设 + 5 个已知场景（greeting/zoo/shopping/weather/body）的轻量 framing + 一条基线安全指令，保证接口可用且产出贴合场景。AI-405 可无缝替换为可配置场景包系统。**不越界实现 AI-405 的完整场景包/内容安全层**。
- **TTS 持久化**：真实 provider 返回 base64（无 URL），data URI 可能超 512 字符，故 `audioPath` 持久化留待 AI-407（写对象存储/磁盘后存路径）；本 feature 仅通过响应 `ttsUrl` 返回即时播放引用。
- **鉴权推迟**：与全项目 AI 接口一致，本接口暂不鉴权；userId 默认 `anonymous`，待统一鉴权 feature 接入后切换解析器。
