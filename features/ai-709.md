# AI-709 — child 端「更多」tab（卡片网格抽屉）收纳孤儿二级页

> 状态: in-progress | 栈: node-ts (Next.js 14 App Router + React 18, Tailwind) | 分支: feat/ai-709
> 来源: AI-708 收尾后用户确认（child 仅 4 个 tab，第 5 个做微信小程序式「更多」tab，方案 A：卡片网格抽屉）。路由可达性核查发现 `/chat` `/plan` `/word-cards` 在孩子 UI 无任何入口（仅 RoleGuard CHILD_ONLY 引用），属孤儿页；本 feature 一并修复。

## 1. 目标
在 child 底栏新增第 5 个「更多」tab，点开是一个**大图标卡片网格抽屉**（底部 sheet），把孤儿/二级页（对话陪练 / 学习计划 / 生词本 / 口语）收纳进去，让孩子能直接进入这些页。用户价值：消除导航缺口（对话陪练等核心功能此前孩子点不到）；沿用微信小程序「更多」范式且适配 5-10 岁认图不认字（大卡片而非文字列表）。

## 2. 接口契约
### 后端（如有）
- 无。纯前端导航组件改动，不改变任何 API / DTO / 路由结构（目标路由 `/chat` `/plan` `/word-cards` `/speech` 已由 RoleGuard 声明为 child 可见，仅缺入口）。

### 前端（如有）
- `src/components/TabNav.tsx`：`childTabs` 追加第 5 项 `more`（`LayoutGrid` 图标，`href` 占位 `#more`，点击 `setMoreOpen(true)` 而非导航）；`isActive` 增加「more 激活」判定（当前 pathname ∈ {`/chat`,`/plan`,`/word-cards`,`/speech`} 时高亮）。
- 新增 `src/components/MoreDrawer.tsx`：底部抽屉（`fixed inset-0 z-[70] bg-black/40` 遮罩 + `fixed bottom-0 ... rounded-t-[28px]` 面板），内含标题 + 2 列大图标卡片网格；卡片为 `Link`（导航到目标路由并 `onClose`）；遮罩点击 / 关闭按钮 / 路由变化均关闭；`role="dialog"` + `aria-modal` + 关闭按钮 `aria-label`。
- i18n：`TabNav.more`（更多 / More）；新增 `MoreDrawer` 命名空间：`title`（更多功能 / More）、`chat`（对话陪练 / Chat）、`plan`（学习计划 / Plan）、`wordCards`（生词本 / Word Cards）、`speech`（口语 / Speak）、`close`（关闭 / Close）。

## 3. 数据模型
- 无新增实体 / 表 / 迁移。

## 4. 验收标准
- [ ] child 底栏可见第 5 个「更多」tab（图标 `LayoutGrid`）。
- [ ] 点击「更多」弹出底部抽屉，内含 4 张大图标卡片：对话陪练 / 学习计划 / 生词本 / 口语。
- [ ] 点击任一张卡片导航到对应路由（`/chat` `/plan` `/word-cards` `/speech`）且抽屉关闭。
- [ ] 遮罩点击 / 关闭按钮可关闭抽屉。
- [ ] 当前路由为 more 集合中任一页时，「更多」tab 高亮。
- [ ] parent 端底栏不变（仍 3 个 tab），「更多」仅 child 可见。
- [ ] i18n：zh/en 下 `TabNav.more` 与 `MoreDrawer.*` 6 键齐备，i18n-messages.spec 2/2。
- [ ] 抽屉 `z-[70]` 高于 `LocaleSwitcher`(`z-[60]`)，语言药丸不被抽屉遮挡逻辑冲突。

## 5. 风险点
- **纯前端组件，零运行时逻辑风险**：无类型契约 / 鉴权 / 破坏性改动，回滚安全。
- **抽屉 z-index**：用 `z-[70]` 确保盖过 `LocaleSwitcher`(`z-[60]`) 的浮动层，避免语言药丸浮在抽屉上。
- **i18n 键必须字面量**：卡片标签用字面量 `t('MoreDrawer.chat')` 等（不用模板字符串），否则 i18n-messages.spec 扫描漏检导致键缺失。
- **不触碰 parent 端 / 其他页面布局**：仅改 TabNav + 新增 MoreDrawer，符合「更多」收纳范畴，避免借机重构。
