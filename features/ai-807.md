# AI-807 — 无障碍关键修复（语义 / 焦点 / 实时区域）

> 里程碑：M13（UI 设计规范整改与无障碍加固）· 优先级 **P0**
> 分支：`feat/ai-807`（基于 `feat/ai-806` / 最新集成分支）
> 关联：`AI-805`（弹层语义由 Dialog 接管）、`AI-706`（i18n 已落地）

## 背景与目标

首轮 UI 设计规范审查（见 `ui-review-report.md`）与 `Web 界面设计规范` 核查暴露出一批 **WCAG / 可访问性关键缺口**：

- `practice` 页同一视图出现多个 `<h1>`，且 listen 模式完全没有标题（读屏用户失去上下文锚点）；
- 全站缺少「跳到主内容」skip-link，键盘用户首屏必须逐级穿过导航；
- `select` 下拉长列表用 `overflow-hidden`，选项多时会溢出视口、无法滚动；
- `progress-ring` 用 `role="img"`（无 `aria-valuenow`），`progress` 条缺可访问名；
- 聊天线程、录音/加载态、各页错误卡未暴露给读屏（缺 `aria-live` / `role="alert"` / `role="status"`）；
- `Field` 组件要求调用方手写 `id`/`htmlFor`，易漏；
- `picture-book` 生成按钮因漏写 JSX 括号，直接显示字面量 `t('generate')` 而非翻译文案。

本 feature 按 WCAG 2.1 与 WAI-ARIA 1.2 收口以上问题。

## 改动清单

### 1. 标题语义（practice 页）`src/app/[locale]/practice/page.tsx`
- 每个视图（完成态 / 空模式 / 主练习 / 无词）统一注入一个**视觉隐藏的页面级 `<h1>{t("practiceTitle")}</h1>`**；
- 原单词标题（`:474` multiple、`508` combination）由 `<h1>` 降为 `<h2>`，并前置 `<span className="sr-only">{t("currentWord")}</span>` 给读屏明确「当前单词」语义；
- 完成态 `Amazing Job!`（`:352`）、空模式标题（`:394`）、无词标题（`:666`）均降为 `<h2>`；
- listen 模式（`ListenPrompt`）补 `<h2 className="sr-only">{t("listenPromptHeading")}</h2>`（原先无任何标题）。
- 结果：**每个视图唯一 `<h1>` 且无空标题**，层级明确。

### 2. 跳过导航 + 主内容锚点 `src/app/[locale]/layout.tsx`
- `<body>` 首行新增 skip-link：
  `<a href="#main" className="sr-only focus:not-sr-only focus:absolute ...">{t("skipToContent")}</a>`（首个可聚焦元素，键盘 Tab 即达）；
- `<main>` 加 `id="main"`，成为跳转目标；
- 服务端 `getTranslations("TabNav")` 取文案，新增 i18n 键 `TabNav.skipToContent`。

### 3. Select 下拉可滚动 `src/components/ui/select.tsx`
- 列表容器 `overflow-hidden` → `max-h-72 overflow-y-auto`，长列表不溢出视口、可滚动（仍 `rounded-card` 裁切圆角）。

### 4. Progress 可访问名 `src/components/ui/progress.tsx` + `progress-ring.tsx`
- `Progress` 新增可选 `aria-label` 属性并落到 `role="progressbar"` 容器；practice 调用处传 `aria-label={t("progressLabel")}`；
- `ProgressRing` 由 `role="img"` 改为 `role="progressbar"`，补 `aria-valuenow/min/max`（与中心百分比文本一致，SVG 叶子角色抑制内部文本重复播报）。

### 5. 实时区域（读屏可见）`chat` / `SpeechRecorder` / `AuthGate` / `rewards` / `parent-report` / `parent/settings`
- `chat/page.tsx` 聊天线程容器加 `role="log" aria-live="polite" aria-relevant="additions"`；
- `SpeechRecorder.tsx` 「请求麦克风」加载态包 `<div role="status" aria-live="polite">`；
- `AuthGate.tsx` 未登录加载态加 `role="status" aria-live="polite"`；
- `rewards`、`parent-report` 错误卡 `Card` 加 `role="alert"`；
- `parent/settings` 的 `ParentError`（`<section>`）与 `ProviderConfigError`（`<p>`）加 `role="alert"`（`ChildError` 此前已有）。

### 6. Field 自动关联 `src/components/ui/input.tsx`
- `Field` 用 `React.useId()` 生成稳定 `id`；未传 `htmlFor` 时通过 `React.cloneElement` 注入到唯一子控件，并自动设置 `aria-invalid` 与 `aria-describedby`（关联 hint/error）；
- 调用方无需手写 `id`/`htmlFor` 即可获得程序化 label 关联。
- 注：当前 `Field` 尚未被页面直接引用（login/word-cards 仍用裸 `<label htmlFor>`），本次为原语能力补全，后续迁移可选。

### 7. picture-book 文案 bug `src/app/[locale]/picture-book/page.tsx`
- 生成按钮字面量 `t('generate')` → `{t('generate')}`，正确渲染翻译「Generate Book / 生成绘本」（键 `PictureBook.generate` 已存在）。

### 8. i18n 键
- `TabNav.skipToContent`（Skip to main content / 跳到主要内容）；
- `Practice.practiceTitle` / `currentWord` / `listenPromptHeading` / `progressLabel`。
