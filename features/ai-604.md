# AI-604 — AI 绘本生成

> 状态: in-progress | 栈: node-ts (NestJS 10 + TypeORM + better-sqlite3 / Next.js 14) | 分支: feat/ai-604
> 来源: backlog M6（P2），依赖 AI-601（单词卡生成，done）、AI-402（TTS，done）

## 1. 目标

课程完成后，按本课单词自动生成一篇短篇**故事绘本**（多页文本 + 每页配图提示 + 封面配图提示），孩子可在前端**逐页阅读并可朗读（TTS）**。绘本按 `(userId, courseId)` 幂等生成一次，AI 失败/解析失败时降级为内置模板绘本（不 5xx）。

用户价值：把枯燥的单词复习变成可朗读的童趣故事，强化记忆与成就感。

## 2. 接口契约

### 后端
- `GET /api/ai/picture-book?userId=<id>&courseId=<id>`（courseId 可空）
  - 成功：`200` + `PictureBookResponse`
  - `PictureBookResponse { id?: string; courseId: string; title: string; pages: PictureBookPage[]; isDefault: boolean; createdAt?: string }`
  - `PictureBookPage { pageNumber: number; text: string; illustrationPrompt: string }`
  - 幂等：`(userId, courseId)` 已存在直接返回快照；否则调 `AiProvider.chat` 生成→解析→落库。
  - `courseId` 为空/课程无单词 → 仍返回绘本（内容不含本课单词，覆盖率低），属预期。
- `POST /api/ai/picture-book/tts`，body `{ text: string }`，返回 `{ ttsUrl: string | null }`
  - 调用 `aiProvider.synthesize(text)`；有 `audioUrl` 用 URL，有 `audioBase64` 包 `data:` URL，否则 `null`（前端优雅降级无声）。
  - 限长：text 非空且 ≤ 2000 字符，否则 `400`。

> 鉴权：与 AI 模块约定一致（无 `JwtAuthGuard`，`userId` 由 query 传入；已知限制：userId 客户端传入、未做租户隔离，待全局鉴权落地后统一收紧）。

### 前端
- `src/lib/api.ts`：`getPictureBook(courseId?: string): Promise<PictureBook>`；`requestPictureBookTts(text: string): Promise<{ ttsUrl: string | null }>`。
- `src/lib/types.ts`：`PictureBook` / `PictureBookPage`。
- 路由 `src/app/picture-book/page.tsx`：加载 `getCourses()` 展示课程选择器；「示例绘本」按钮（courseId 空 → 默认绘本，免种子）；阅读器弹层逐页展示文本 + 配图提示 + 「朗读」按钮（调 `requestPictureBookTts` → `playTts`）。
- `src/components/TabNav.tsx`：新增「绘本」入口 → `/picture-book`。

## 3. 数据模型

`server/src/ai/picture-book.entity.ts` — `@Entity('picture_books')`，`@Unique(['userId', 'courseId'])`：

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid (PK) | |
| userId | varchar(255) @Index | 沿用 `ai_reports` 口径（varchar 非硬外键） |
| courseId | varchar(255) | 空串表示示例/默认绘本 |
| title | varchar(255) | 绘本标题 |
| storyText | text | 全本正文（页文本拼接，便于覆盖统计/检索） |
| pages | text | JSON：`PictureBookPage[]`（pageNumber/text/illustrationPrompt） |
| coverImagePrompt | varchar(255) | 封面配图提示 |
| isDefault | boolean | true=模板降级（非真实 AI 生成） |
| createdAt | CreateDateColumn | |

> **配图说明**：本项目 `AiProvider` 无文生图方法（仅 `chatWithImage` 图→文）。绘本「配图」以 `illustrationPrompt` 文本呈现（与 AI-601「配图 prompt」口径一致），前端显示为配图提示卡，不调用外部生图。后续若接入文生图，可在此字段基础上扩展。

取词：服务注入 `Repository<Course>`/`Repository<Lesson>`/`Repository<Word>`，用 `courseRepo.find({ where:{id}, relations:['lessons','lessons.words'] })` 摊平本课单词，喂给 Agent 要求覆盖。

## 4. 验收标准
- [ ] `GET /ai/picture-book` 对 `(userId, courseId)` 幂等：首次生成、二次直返。
- [ ] 有单词的课程生成绘本，**覆盖 ≥80% 本课单词**（单元测试断言 `computeWordCoverage`）。
- [ ] AI 失败/返回非法 JSON → 降级默认绘本（`isDefault:true`），不抛 5xx。
- [ ] `POST /ai/picture-book/tts` 对任意文本返回 `ttsUrl`（mock 下为 null，前端静默降级）。
- [ ] 前端 `/picture-book` 页面：课程选择器 + 示例绘本 + 阅读器；每页可朗读。
- [ ] E2E：新用户登录 → 看到绘本区 → 点示例绘本 → 弹层标题非空 + ≥1 页文本非空。

## 5. 风险点
- **单词覆盖**：依赖 LLM 真正把单词编进故事；以 `computeWordCoverage` 在单测中验证 ≥80%，真实调用无法 100% 保证（模型不确定性），属可接受范围，覆盖率仅作质量信号。
- **并发 race**：`(userId, courseId)` 唯一约束并发写 → 捕获 `UNIQUE` 回查已有（仿 AI-603）。
- **端口/起服**：沿用历史坑——起服前清掉遗留 NestJS(:4000)/Next(:3000)；E2E 后端 `AI_PROVIDER=mock`、前端 `next build`+`next start`。
- **配图非真实图**：诚实标注，不伪造成图。
