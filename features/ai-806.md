# AI-806 设计 token 统一与对比度核算

> 收口 `features/backlog.md` M13 · AI-806（P1）。基线分支：`master`（AI-804 合并后 HEAD `3825346`），本 feature 在 `feat/ai-806` 分支完成。

## 1. 目标

- 全站单一 `--seed-primary`，`progress-ring` 与 `LevelRing` 视觉一致。
- 收口 `practice` / `plan` 散落的硬编码 UI 色进 `docs/design-system.md` token。
- 核算并修复关键文本（≥4.5:1）/ 非文本（≥3:1）对比度不达标项（WCAG 2.1 AA）。
- `prefers-reduced-motion` 守卫覆盖进度环过渡（动效抽成可被覆盖的 CSS class）。
- 前端 `tsc --noEmit` 0。

## 2. 根因与决策

原 `--seed-primary: #19C8B9`（亮青）配白字仅 **2.10:1**，远低于文本 4.5:1；`--color-success: #6FBA2C` 配白字 **2.40:1**。`TabNav` 激活态、主按钮、链接、`::selection`、primary 链接全部踩雷。`LevelRing.tsx:58` 的 fallback `#F59E0B`（琥珀）与 `progress-ring` 的 `#19C8B9` 字面冲突——但 `--seed-primary` 已被定义，二者实际同色，真实问题只是 fallback 字面不一致。

**方案**：下调主色系到深青 `#0B7A70`（保留品牌青绿、白字 5.21:1、链接 4.88:1），而非逐个改白字用法。彩色「粉/蓝/青/黄/绿」浅色板天生无法承载白字（1.7~3.6:1）或浅底彩色文字，因此新增强色调变体专门用于「实色填充 + 文字」控件。

## 4. 对比度核算结果

运行 `node scripts/contrast-audit.mjs`：

- **BEFORE**：11 项关键对全部 ❌（主按钮/成功/`TabNav`/`::selection`/链接/计划徽章 1.77~2.74:1，答题按钮 1.72~2.58:1）。
- **AFTER**：19 项关键对全部 ✅（文本 ≥4.5:1、非文本色条 ≥3:1）。主色白字 5.21:1、成功 5.24:1、链接 4.88:1、答题按钮 5.02~7.90:1、计划徽章/色条 5.02~6.70:1。

## 5. 验收对照（backlog 标准）

- ✅ 全站单一 `--seed-primary`，`progress-ring`/`LevelRing` 一致（fallback 字面对齐 `#0B7A70`）。
- ✅ 无散落硬编码 UI 色（答题按钮、计划徽章/色条全部走 token；单词内容豁免）。
- ✅ 关键文本/非文本对比度达标，附 `scripts/contrast-audit.mjs` 核算记录。
- ✅ `prefers-reduced-motion` 守卫生效（全局 `*` 过渡 0.01ms 覆盖，`.ring-progress` 改用 class）。
- ✅ 前端 `tsc --noEmit` 0。

## 6. 残余项（超出本 feature 重点，建议后续）

- `kids.muted` `#9F927D` on 卡片 `#F7F3DF` ≈ **2.72:1**（次要辅助文字），未达 4.5:1。建议在 AI-807 或专项中下调 `--color-muted` 至 ≥4.5:1。
- `kids.mint-wash`（`#E6F9F6`）、`kids.leaf`（`#6FBA2C`）等浅/亮色仅用于非文字装饰（wash、图标），本 feature 不改其语义。
