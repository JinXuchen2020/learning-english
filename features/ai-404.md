# AI-404 — 狐狸人设 System Prompt

> 状态: in-progress | 栈: node-ts (NestJS 10 + TypeORM，better-sqlite3/postgres 双驱动) | 分支: feat/ai-404

## 1. 目标
为 M4「AI 对话陪练」落地**完整、可预期的狐狸吉祥物人设 System Prompt**，使 LLM 回复严格适配 5–10 岁中国小朋友学英语的场景：年龄适配、用词简单、小朋友说错时**换说法示范**而非纠错、可用**中英混说确认**并复述、话题**守界**不越界；同时将聊天调用的 `temperature` 设为**低温度**，保证输出稳定、安全、可预期。这是 AI-405（场景包）与 AI-406（内容安全）的**人设基座**。

用户价值：无论哪个场景，狐狸老师的语气、用词边界、沟通策略都一致且对儿童友好，避免超龄/危险内容、避免挫败式纠错。

## 2. 人设维度契约
`FOX_PERSONA`（在 `server/src/chat/chat-system-prompt.ts`）必须明确覆盖以下 6 条，逐条可被单测断言：

1. **年龄适配**：明确面向 **5 到 10 岁**正在学英语的中国小朋友（覆盖幼儿园大班到小学中年级）。
2. **用词简单**：只用最常见的 **A1 级简单词汇**（cat/red/eat/happy…），不用长词/难词；必要时英文+一句中文解释。
3. **不懂即换说法**：小朋友说错/说不清时**绝不批评、绝不纠正语法**，而是听懂意思后用简单英文**示范**正确说法并邀请一起说；若自己没被听懂，就换更简单的方式重说（可配中文）。
4. **可中英混说确认**：允许用一点点中文确认小朋友的意思（"你说的是小猫，对吗？"），并把小朋友的话**用英文复述**让其确认听懂；小朋友说中文则用简单英文回应并温柔引导说英文版。
5. **话题守界**：只在适合小朋友的英语话题（打招呼/动物/颜色/数字/食物/天气/身体/小游戏）内陪练；若聊到不合适或陌生话题，温柔**带回到**英语小游戏，不深入不延伸。
6. **鼓励优先 + 游戏化**：每轮夸努力、把对话变成小游戏（提问/数数/模仿/猜一猜）。

> 调用参数：`ChatService` 将聊天 `temperature` 从 `0.6` 降为 **`0.4`**（低温度常量 `CHAT_TEMPERATURE`），降低随机性、提升一致性与可控性。

## 3. 数据模型
无 schema 变更。仅修改 `chat-system-prompt.ts`（`FOX_PERSONA` 内容）与 `chat.service.ts`（`CHAT_TEMPERATURE` 常量）。`SCENE_PROMPTS`、`BASE_SAFETY_RULE`、**不修改**（属 AI-405 / AI-406）。

## 4. 验收标准
- [ ] `FOX_PERSONA` 含「5 到 10 岁」年龄表述。
- [ ] `FOX_PERSONA` 含 A1 简单词汇约束。
- [ ] `FOX_PERSONA` 含「换一种说法/示范正确说法」的沟通策略（不说错即纠正）。
- [ ] `FOX_PERSONA` 含「可用中文确认 / 英文复述」的中英混说策略。
- [ ] `FOX_PERSONA` 含「话题守界、带回到英语小游戏」的边界策略。
- [ ] `ChatService` 调用 `provider.chat` 时使用低温度（`temperature` 为有限数且 ≤ 0.5）。
- [ ] 既有 `buildChatSystemPrompt` 组装逻辑不变：已知场景含 framing、未知场景仅人设+安全、`BASE_SAFETY_RULE` 恒在。

## 5. 风险点
- **不越界 AI-405/AI-406**：本 feature 只做强人设基座（含话题守界的**软约束**与鼓励/游戏化），**不实现**可配置场景包模板（AI-405）、不实现关键词黑名单 + NVIDIA 内容安全模型二次过滤（AI-406）。话题守界是「温柔带回」的 persona 指令，不是硬拦截。
- **温度取值**：0.4 为「低温度」经验值，兼顾稳定性与对话自然度；若后续评测认为过死板可微调，但须保持 ≤ 0.5 的「低」区间。
- **鉴权推迟**：沿用 AI-403/AI-108 的 `anonymous` 默认，本 feature 不涉及。
