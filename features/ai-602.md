# AI-602 — AI 难度自适应

> 状态: done | 栈: node-ts (Next.js 14 + NestJS 10) | 分支: feat/ai-602
> 依赖: 现有 ProgressModule (word_progress), AI-306 (ScoreResult.score)

## 1. 目标
根据孩子对单词的**正确率**与**发音评分**，自动调整该单词的难度档位（easy / medium / hard），
并据此对练习词表做**复习优先级排序**——掌握度低的词更频繁出现（"错题更频繁出现"），
掌握度高的词自动升级到更难档位（"正确率高自动升级难度"）。纯后端数据驱动 + 前端自适应排序，
不依赖 LLM，无 key 也能跑通。

## 2. 接口契约

### 后端（ProgressModule 扩展）
- `POST /progress/word`（既有，增强）：请求体加 DTO 校验
  - body: `{ wordId: string; correct: boolean }`（`RecordWordAttemptDto`，`@IsString() @IsNotEmpty()` + `@IsBoolean()`）
  - 响应新增字段：`mastery: number`(0-100)、`difficulty: 'easy'|'medium'|'hard'`
- `GET /progress/word-difficulty`（新增）：返回当前用户所有已练单词的自适应画像
  - 响应：`{ items: WordDifficultyInfo[] }`
  - `WordDifficultyInfo = { wordId: string; difficulty: WordDifficulty; mastery: number; reviewPriority: number }`

### 前端
- `getWordDifficulties(): Promise<WordDifficultyInfo[]>` → `GET /progress/word-difficulty`
- `/practice` 自由练习（无 lessonId）时：并行拉 `getAllWords()` + `getWordDifficulties()`，
  按 `reviewPriority` 降序排序（弱词在前），并在每张单词卡显示 `data-difficulty` 徽章。

## 3. 数据模型
`server/src/entities/word-progress.entity.ts` 新增两列（**显式 type，避免 AI-601 的联合类型反射坑**）：
```typescript
@Column({ type: 'varchar', default: 'easy' })
difficulty: WordDifficulty;        // 'easy' | 'medium' | 'hard'

@Column({ type: 'int', default: 0 })
mastery: number;                   // 0-100，= round(correctCount/attempts*100)
```
`WordDifficulty` 类型定义在 `word-progress.entity.ts` 导出（`export type WordDifficulty = 'easy' | 'medium' | 'hard'`）。

## 4. 自适应算法（纯函数，集中在 `ProgressService` 并便于单测）
- `computeMastery(attempts, correctCount)`: attempts=0 → 0；否则 `round(correctCount/attempts*100)`。
- `computeDifficulty(mastery, attempts)`: 需至少 3 次练习才有样本调整档位，避免过早升级
  - attempts >= 3 && mastery >= 80 → `'hard'`（正确率高自动升级）
  - attempts >= 3 && mastery >= 50 → `'medium'`
  - 否则（练习 <3 次或掌握度 <50%）→ `'easy'`
- `computeReviewPriority(mastery, lastPracticedAtMs?)`: `(100 - mastery) + daysSinceLastPractice * 5`
  （未练过 → daysSince 默认 14 天，给基础权重；自由练习只排已练词，未练词保持默认顺序）

## 6. 风险点
- **TypeORM 联合类型反射**：同 AI-601，`difficulty` 用 `@Column({ type: 'varchar', default: 'easy' })` 显式声明，
  `mastery` 用 `@Column({ type: 'int', default: 0 })`。切忌 `@Column({ nullable: true })` 不带 type。
- **不改 `getAllWords` 契约**：自由练习排序在前端做，后端 `GET /words` 不变，避免破坏既有页面。
- **score 来自 AI-306**：本 feature 暂只消费 word 练习的正确率（quiz 是选词，非发音评测）。
  发音评分（ScoreResult.score）接入留作后续增强，本 feature 不在练习路径耦合 STT。
