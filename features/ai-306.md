# AI-306 — 口语评分反馈 + 持久化

> Feature: `feat/ai-306` · 里程碑: M3（口语训练）· 优先级: P0
> 依赖: AI-301（`ai_speech_attempts` 实体 + `AiSpeechAttemptService`）、AI-305（`AiPronunciationScorerService` 统一 `ScoreResult`）
> 上游: AI-303 评测接口（`POST /api/ai/speech/evaluate`）调用本 feature
> 下游: AI-307（`/speech` 页消费反馈结构）、AI-602（难度自适应消费落库分数）

## 1. 目标

把 AI-305 产出的统一 `ScoreResult` 转化为**面向儿童用户的口语反馈**，并把评分与弱音素**持久化**到
AI-301 的 `ai_speech_attempts` 表，供 AI-307（历史/星级）与 AI-602（难度自适应）消费。

验收标准（来自 backlog）：
- 返回 `score / readableText / weakPhonemes / feedback / mascotExpr`
- 通过线 **60 分**（`passed` 布尔）
- 分数与弱音素**正确入库**（`ai_speech_attempts`）；`weakPhonemes` 可展示（simple-array 往返）

## 2. 反馈结构（新增，纯逻辑可测）

```ts
export const PASS_LINE = 60;

export type SpeechLevel = 'good' | 'ok' | 'weak';

export interface SpeechFeedback extends ScoreResult {
  /** 是否通过（score >= PASS_LINE）。 */
  passed: boolean;
  /** 等级档位：good(≥80) / ok(≥60) / weak(<60)。 */
  level: SpeechLevel;
  /** 吉祥物表情（优先取 ScoreResult.mascotExpr，否则按分数推断）。 */
  mascotExpr: string;
}
```

- `buildSpeechFeedback(result: ScoreResult): SpeechFeedback`
  - `passed = result.score >= PASS_LINE`
  - `level = levelFromScore(result.score)`（good: ≥80, ok: ≥PASS_LINE[60], weak: <60）
  - `mascotExpr = result.mascotExpr || inferMascotExpr(result.score)`
  - 透传 `score / readableText / weakPhonemes / feedback`
- `levelFromScore(score): SpeechLevel` — 边界用 `>=`，纯函数。
- `buildAttemptEntry(userId, dto, result): AiSpeechAttemptEntry` — 组装落库入参（见 §4 占位约定）。

## 3. 服务拆分（遵循本项目 util + 服务组合模式，同 AI-302/304/305）

- `server/src/ai/speech-feedback.util.ts`（**纯逻辑层**，零依赖，node 可测）：
  `PASS_LINE` / `SpeechFeedback` / `SpeechLevel` / `buildSpeechFeedback` / `levelFromScore` /
  `buildAttemptEntry`（落库入参装配）。
- `server/src/ai/ai-speech-feedback.service.ts`（`AiSpeechFeedbackService`）：
  注入 `AiSpeechAttemptService`（AI-301）；
  `feedback(userId, cmd, result): SpeechFeedback`：
  1. **best-effort 落库**：`this.attempts.record(buildAttemptEntry(userId, cmd.dto, result))`
     —— `record` 自身已吞异常（AI-301 best-effort 口径），此处再兜底一次，确保落库失败
     **绝不阻断反馈返回**（与 AI-301/108 口径一致）。
  2. 返回 `buildSpeechFeedback(result)`。

## 4. 落库入参边界（占位约定，保持 AI-301 实体契约稳定）

评测接口（AI-303）当前接收 **multer 内联音频 buffer**，无持久路径；鉴权 deferred（`userId`
走请求体，与本项目 M2 链既有口径一致）。因此：

- `EvaluateSpeechDto` 增加两个可选字段：
  - `userId?: string` — 归属用户；**未提供 → 落库用 `'anonymous'`**（与 `USER_ID_RESOLVER_TOKEN`
    默认 `() => 'anonymous'` 同口径）。
  - `audioPath?: string` — 音频持久路径；**未提供（inline 上传场景）→ 落库用占位 `'<inline>'`**
    （语义化标识"内联音频未落盘"，由后续存储 feature 完善）。
- `buildAttemptEntry` 用上述占位，满足 AI-301 `audioPath` non-nullable 约束，**不改 entity**。
- 设计文档 §7 明确：音频持久化/对象存储不在本 feature 范围，仅记录评分（inline 场景
  `audioPath` 占位），避免越界。

## 5. 接入评测流程（AI-303 改造）

`AiSpeechEvaluatorService.evaluate()`：
- 注入 `AiSpeechFeedbackService`（替代对落库的无作为）。
- 流程：校验 → 解析参考文本 → `scorer.score(...)` →
  `return this.feedback.feedback(dto.userId ?? 'anonymous', cmd, score)`。
- 返回类型由 `ScoreResult` → `SpeechFeedback`（增强结构）。
- `AiController.evaluate` 直接返回 evaluator 结果，无需改翻译逻辑；返回体即 `SpeechFeedback`。

## 7. 边界与约定

- **不越界**：不引入新实体/Repository 依赖（复用 AI-301 `AiSpeechAttemptService`）；不接 auth
  （deferred，userId 走 body）；不落盘音频（属后续存储 feature，inline 场景占位）。
- **降级不抛**：落库失败 best-effort（与 AI-301/108 同口径），绝不阻断孩子的口语反馈。
- **分数边界**：`ScoreResult.score` 已由 AI-305 clamp[0,100]；落库层 AI-301 再 `clampScore` 兜底。
- **真实 Azure 音素级**：AI-305 已处理端点缺失降级；本 feature 不感知具体评分算法。
