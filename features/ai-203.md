# AI-203 — PlanAgent System Prompt（双语儿科友好）

> 状态: in-progress | 栈: node-ts (NestJS) | 分支: feat/ai-203

## 1. 目标

把 AI-202 的「最小可运行占位提示词」替换为生产级 **PlanAgent System Prompt**：
中文语境 + 英文学习材料、儿科友好、内容安全红线、结构化日计划（1 主课 + 2 复习 + 1 口语）、
间隔复习、技能交错（vocab/listen/speak/write）、要求引用真实 `courseId`/`lessonId`。
让 LLM 产出可被 AI-204（Schema 校验）/ AI-206（落库映射任务）消费的语义正确计划。

用户价值：计划更贴合儿童认知、内容安全可控、且能对齐平台真实课程目录（不编造 id）。

## 2. 接口契约

### 后端（复用 AI-202 接口，不改路由/DTO）
- `POST /api/ai/plan/generate` 不变；`GeneratePlanDto` 不变。
- 仅替换 `PlanService.buildMessages` 使用的 system prompt 与 user 消息组装逻辑。
- `buildPlanUserPrompt(dto, catalog?)` 新增第二个可选参数 `catalog`：
  - 传 `undefined`（AI-203 默认）→ 仅发学习者画像 JSON，并提示模型「目录稍后注入，须映射到真实 id」。
  - 传 `PlanCatalog`（AI-204/206 注入）→ 附真实课程/课时目录，要求逐节引用真实 `courseId`/`lessonId`。

### 提示词核心要素（验收直接映射）
1. **双语儿科友好**：以中文做引导/讲解，英文做学习内容；语气鼓励、用词简单、适配 5–10 岁。
2. **每日结构**：1 主课（main）+ 2 复习（review）+ 1 口语（speaking），避免一天过载。
3. **间隔复习（spaced review）**：新词/新课在后续天数按间隔（如 +1、+3 天）循环复习。
4. **技能交错**：vocab / listen / speak / write 在周计划内交错分布，不连续同类堆叠。
5. **内容安全红线**：禁止超龄（暴力/恐怖/成人/政治/宗教敏感）、危险动作、不当价值观；
   不出现真实姓名/联系方式；不鼓励屏幕超时。
6. **引用真实 id**：当目录提供时，每节 `courseId`/`lessonId` 必须为目录中真实 UUID，禁止编造。
7. **低 temperature**：与 `PlanService` 已设 `temperature:0.4` 一致，提示词重申「稳定、少随机」。
8. **仅输出 JSON**：严格 `{"weeks":[{"week","days":[{"day","skillType","title","lessons":[{"type","title","skillType","courseId?","lessonId?","description"}]}]}]}`，
   无解释、无 Markdown 围栏（服务侧仍 `extractJson` 兜底）。

- [ ] 无超龄/危险内容（内容安全红线在提示词中确立；双保险关键词/模型过滤属 AI-406）。

## 5. 风险点
- **目录未注入**：AI-203 默认无目录，模型无法引用真实 id。已在提示词注明「目录稍后注入，须映射真实 id」，
  真实闭环由 AI-204（Schema 校验 `courseId`/`lessonId` 存在性）/ AI-206（注入目录并落库）完成，不在此 feature 越界注入 CoursesModule 查询。
- **过度构建**：严格限于「提示词 + 组装函数 + 承载类型」，不写 Schema 校验、不查库、不加接口，遵守 skill 护栏。
