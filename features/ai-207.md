# AI-207 — `/plan` 页面：学习计划向导表单

> 状态: in-progress | 栈: node-ts (Next.js 前端 + NestJS 后端) | 分支: feat/ai-207
> 依赖: AI-202 (generate 接口) | 下游: AI-208 (计划展示与交互)

## 1. 目标

为已登录的孩子提供一页式「学习计划向导」：用大触控目标的卡片选择器收集
年龄段 / 等级 / 每日时长 / 兴趣 / 周数，提交后调用 `POST /api/ai/plan/generate`
得到计划，并就地给出基础预览（含「模板兜底」`degraded` 提示与错误态）。
让 `/plan` 成为 M2 学习计划闭环的真实入口。

## 2. 接口契约

### 后端（已存在，AI-202/205，本 feature 不新增后端代码）
- `POST /api/ai/plan/generate`
  - 请求体 `GeneratePlanDto`：`childId`(uuid) `ageRange`("lo-hi") `level`(pre-a1|a1|a2)
    `dailyMinutes`(5-120) `interests`(string[],≥1) `weeks`(1-4) `useTemplate?`(bool)
  - 响应 `GeneratePlanResponse`：`{ plan: GeneratedPlan, model?, degraded: boolean }`
  - 无 LLM key 时（MockProvider）自动降级为内置模板计划 → 仍 200，`degraded:true`，`plan` 有效可渲染。

### 前端（本 feature 新增）
- 新增 `lib/types.ts`：`PlanSkillType` / `PlanLevel` / `PlanLesson` / `PlanDay` / `PlanWeek`
  / `GeneratedPlan` / `GeneratePlanResponse` / `GeneratePlanDto`。
- 新增 `lib/plan.ts`（**纯逻辑模块**，可单测）：选择器常量
  (`PLAN_LEVELS` / `AGE_RANGES` / `DAILY_MINUTE_OPTIONS` / `INTEREST_OPTIONS` / `WEEK_OPTIONS`)
  + `validatePlanForm(values): PlanFormErrors`（缺字段即返回对应报错文案）。
- 扩展 `lib/api.ts`：`generatePlan(dto: GeneratePlanDto): Promise<GeneratePlanResponse>`。
- 新增 `app/plan/page.tsx`（`"use client"`，`AuthGate` 包裹）：
  - `childId` 取自 `useAuth().user.id`（uuid，满足 DTO）。
  - 五组选择器均为大触控卡片（`touch-target`），选中态高亮；兴趣为多选。
  - 提交按钮在 `validatePlanForm` 通过前 `disabled`（含空表单禁用态，便于 E2E 断言）。
  - 提交中：Mascot `thinking` + loading 区；成功：`PlanPreview` 渲染 weeks→days→lessons，
    `degraded` 为真时显示「Foxy 用了一套现成计划」友好提示；失败：错误提示。
  - 挂载 `data-component` 钩子：`PlanWizard` / `PlanForm` / `PlanLoading` / `PlanPreview`
    / `PlanDegradedNote`，选择器用 `button[data-field=...][data-value=...]` 便于 E2E 定位。
- `components/TabNav.tsx`：新增 `Plan` 标签（Sparkles 图标，href `/plan`）。

## 3. 数据模型
无新增后端表/字段（generate 为无状态调用；持久化属 AI-206 的 save/apply，展示属 AI-208）。

## 4. 验收标准
- [ ] 已登录用户访问 `/plan` 看到完整向导（5 组选择器 + 提交按钮）。
- [ ] 空表单时提交按钮禁用；填写完整后启用。
- [ ] 提交调用 generate 接口，loading → 预览渲染出 weeks/days/lessons。
- [ ] 无 key 环境降级返回仍正确渲染预览并提示 `degraded`。
- [ ] 接口报错时显示错误提示而非白屏。
- [ ] 表单校验逻辑有单元测试覆盖（正常/各字段缺失）。

## 5. 风险点
- **E2E 需双服务在线**：本 feature 的 BDD/E2E 需同时起前端(:3000)与后端(:4000)，
  用系统 Edge（`E2E_BROWSER_CHANNEL` 默认 `msedge`）跑 Playwright，免 Chromium 下载。
- **generate 无鉴权（AI-206 deferred）**：前端照常带 Bearer，后端忽略即可。
- **Preview 边界**：`plan.weeks` 可能为空数组（理论），UI 需空态保护。
