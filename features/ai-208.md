# AI-208 — `/plan` 页面：计划展示与交互

> 状态: in-progress | 栈: node-ts (Next.js 前端 + NestJS 后端) | 分支: feat/ai-208
> 依赖: AI-207 (向导表单) · AI-206 (save/apply 端点) | 下游: AI-209 (计划进度回写)

## 1. 目标

在 AI-207 的向导 + 基础预览之上，把 `/plan` 升级为真正的「计划展示与交互」页：生成后呈现
**每日颜色化的周计划卡片**，提供「重新生成」(带 loading + 模板降级提示) 与「应用此计划」
(调 save→apply→跳转 Home 并在每日任务看到新任务) 两个动作，并支持**单日任务勾选**（本地视觉态，
持久化属 AI-209）。让 M2 学习计划闭环的「生成 → 查看 → 应用」完成。

## 2. 接口契约

### 后端（已存在，AI-206，本 feature 不新增后端代码）
- `POST /api/ai/plan/save`（`SavePlanDto { childId(uuid), plan: GeneratedPlan }`）→ `{ id, status }`（status=`draft`）；结构非法 → 400（复用 AI-204 validatePlan）。
- `POST /api/ai/plan/:id/apply`（`ApplyPlanDto { confirm?: boolean }`）→ `{ id, status:'applied', appliedDays, tasksCreated, appliedAt }`；找不到 → 404；已 applied 且 `!confirm` → 409 `{ code:'PLAN_ALREADY_APPLIED', needsConfirm:true }`；将计划落库为 applied 并按天写 `daily_tasks`（多租户经 `userId`/`planDayId`）。
- 生成仍用 AI-207 的 `POST /api/ai/plan/generate`；MockProvider 无 key 自动降级 `degraded:true` 仍 200。
- **鉴权 deferred**（沿用 AI-206）：前端照常带 Bearer，后端忽略；apply 接口补 JwtAuthGuard 属后续。

### 前端（本 feature 新增/扩展）
- 扩展 `lib/types.ts`：`SavePlanDto` / `SavePlanResponse { id,status }` / `ApplyPlanDto { confirm? }` / `ApplyPlanResponse { id,status,appliedDays,tasksCreated,appliedAt }`。
- 扩展 `lib/api.ts`：`savePlan(dto)` → `POST /ai/plan/save`；`applyPlan(id, dto?)` → `POST /ai/plan/:id/apply`。
- 扩展 `lib/plan.ts`（**纯逻辑模块，可单测**）：`PLAN_SKILL_COLORS`（技能→颜色映射）+ `planSkillColor(skill?)` + `formatPlanDay(day, index)`（返回 `{ label, color, lessonCount, skills }`，标题兜底 `第 N 天`）。
- 增强 `app/plan/page.tsx`（`"use client"` + `AuthGate`）：
  - `PlanPreview` 升级为每日颜色化卡片视图：`plan.weeks` → 每周 `PlanWeekCard` → 每天 `PlanDayCard`（按 `planSkillColor(day.skillType)` 上色、列出 lessons、右侧「单日任务勾选」`button[data-action="toggle-day"][data-day-index=N]` 带 `aria-pressed` 本地视觉态）。
  - 底部动作区：「重新生成」`button[data-action="regenerate"]`（复用 generate，带 `PlanLoading` + `PlanDegradedNote`）；「应用此计划」`button[data-action="apply"]`（save→apply；成功显示 `data-component="PlanAppliedSuccess"` 短暂提示后 `router.push('/')` 跳转 Home；失败 `error` 提示）。
  - 沿用 `data-component` 钩子：`PlanWizard/PlanForm/PlanLoading/PlanPreview/PlanDegradedNote` + 新增 `PlanDayCard/PlanAppliedSuccess`；保留 `PlanWeekCard/PlanDayRow` 兼容 AI-207 E2E。

## 3. 数据模型
无新增后端表/字段（save/apply 属 AI-206；单日勾选本地态，持久化属 AI-209）。

## 4. 验收标准
- [ ] 生成后看到每日颜色化的周计划卡片（按技能类型上色）。
- [ ] 「重新生成」可重新生成计划（loading + 降级提示保留）。
- [ ] 「应用此计划」调 save→apply，成功后跳转 Home，Home 每日任务出现新计划任务。
- [ ] 单日任务可勾选（本地视觉完成态）。
- [ ] 应用失败（如网络/后端错误）显示错误提示而非白屏。

## 5. 风险点
- **E2E 导航**：同 AI-207，必须用 client-side TabNav 点击进入 `/plan` 保 in-memory token；应用成功后跳转 Home 同样 client-side，token 保留。
- **apply 重定向时序**：apply 成功后先显「已应用」提示再 `router.push('/')`，E2E 先等 `PlanAppliedSuccess` 再等 `Home`，避免竞态。
- **DB 持久化跨 E2E 运行**：`replacePlanTasks` 按 `planDayId` 先删后插，重复 apply 覆盖不增行；E2E 断言以「跳 Home + Home 渲染任务」为准，不依赖计数增量（避免 flaky）。
- **单日勾选不落库**：本 feature 仅视觉态；真正回写 `planDay.isDone` 属 AI-209，设计文档显式标注。
