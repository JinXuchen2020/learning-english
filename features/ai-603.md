# AI-603 — 吉祥物成长剧情

> 状态: done | 栈: node-ts (NestJS + Next.js) | 分支: feat/ai-603
> 来源: `features/backlog.md` M6 拓展 (P2)，依赖 AI-501 (`ai_reports` 实体已落地)

## 1. 目标

学习里程碑（**用户等级提升**）触发 AI 生成「吉祥物成长剧情」文案；吉祥物外观/配饰随用户等级升级；吉祥物等级状态持久化到用户。

- 用户价值：增强成长感与情感连接，激励儿童持续学习（产品核心留存钩子的轻量前置）。
- 本期不做：自动弹窗推送、复杂动画；仅提供"主动查看成长故事"入口 + 吉祥物按等级渲染配饰。

## 2. 接口契约

### 后端（NestJS, `server/src/ai/`）

- **`GET /api/ai/mascot/level`** → `MascotLevelInfo`
  ```json
  { "level": 3, "totalStars": 130, "levelStars": 10, "nextLevelStars": 200, "isMaxLevel": false }
  ```
  - 等级计算：`computeLevel(totalStars)`（纯函数）：阈值数组 `LEVEL_THRESHOLDS = [0,50,120,200,300,500]`，落在最后一档之上封顶 level 6。
  - `levelStars` = 当前级已得星 (`totalStars - thresholds[level-1]`)；`nextLevelStars` = 下一级总星阈值（封顶时 = `totalStars`）；`isMaxLevel` 封顶标记。

- **`GET /api/ai/mascot/story/:level`** → `MascotStory`
  ```json
  { "level": 3, "title": "小狐狸的森林舞会", "storyText": "……", "isDefault": false, "createdAt": "2026-08-08T..." }
  ```
  - **幂等**：若该 `(userId, level)` 已有剧情 → 直接返回；否则调用 `AiProvider.chat`（MascotStoryAgent 提示词）→ 解析 `{title, storyText}` → 落库 `mascot_stories` 后返回。
  - **降级**：AI 调用异常 / JSON 解析失败 → 返回内置模板剧情（`isDefault: true`），不抛 5xx。
  - MockProvider 新增「剧情/吉祥物/成长」关键词 + 固定 fixture，保证无 key 环境（开发/E2E）可演示。

### 前端（Next.js, `src/`）

- `src/lib/types.ts`：新增 `MascotLevelInfo`、`MascotStory`。
- `src/lib/api.ts`：新增 `getMascotLevel()`、`getMascotStory(level)`。
- `src/lib/mascotLevel.ts`（**纯逻辑**，与后端 `computeLevel` 同口径）+ `src/lib/mascotLevel.spec.ts`。
- `src/components/Mascot.tsx`：新增 `level?: number` prop，按等级渲染配饰（L1 裸狐 / L2 叶子帽 / L3 围巾 / L4 披风 / L5 光环 / L6 皇冠）。
- `src/app/page.tsx`（Home）：等级环（复用 `ProgressRing` 显示 `levelStars/nextLevelStars` 进度）+ 吉祥物传 `level`；新增"看成长故事"按钮（`data-action="view-growth-story"`）→ 弹层显示当前等级剧情（`getMascotStory(level)`）。

## 3. 数据模型

- **`User.level`**：`server/src/entities/user.entity.ts` 新增 `@Column({ type: 'int', default: 1 })`。等级从 `totalStars` 推导，`synchronize: true` 自动加列（默认 1，不影响现有数据）。写入点：`ProgressService.completeLesson` 星星 +1 后重算并更新（若 chat 模块也累加 `totalStars`，一并统一），保证单一真相。
- **新实体 `MascotStory`**（`server/src/ai/mascot-story.entity.ts`，表 `mascot_stories`）：
  | 字段 | 类型 | 说明 |
  |---|---|---|
  | `id` | uuid PK | |
  | `userId` | varchar(255) `@Index()` | 非硬外键（与 `ai_reports` 口径一致） |
  | `level` | int | 触发时的等级 |
  | `title` | varchar | 剧情标题 |
  | `storyText` | text | 剧情正文 |
  | `isDefault` | boolean default false | 是否模板降级 |
  | `createdAt` | CreateDateColumn | |
  - `@Unique(['userId', 'level'])` 防同等级重复生成。
- **注册**：加入 `server/src/config/database.config.ts` 的 `appEntities` 数组（forRoot 自动建表关键）+ `server/src/ai/ai.module.ts` 的 `TypeOrmModule.forFeature([...])`（注入 Repository）。

## 5. 风险点

- **等级触发时机**：若放在 `completeLesson` 同步调 AI 会增加写入延迟且耦合 → 采用**按需生成**（前端调 `getOrGenerateStory`），避免同步 AI 调用阻塞学习写入。
- **MockProvider**：必须新增剧情关键词/fixture，否则无 key 环境与 E2E 无文案。
- **User.level ↔ totalStars 一致性**：单一计算函数 `computeLevel` + 在 `totalStars` 变化的唯一写入点更新 `level`。
- **等级提升自动弹剧情**：本期简化为"主动查看"入口（前端不记忆上次等级），避免引入 localStorage 状态复杂度；后续 feature 可加自动推送。
