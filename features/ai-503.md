# AI-503 · ReportAgent System Prompt 精炼

> 模块：M5「AI 错题与进度报告」· 阶段：feature-builder（Craft）
> 依赖：AI-502（report-agent.ts 默认提示 + 解析 + 接口落地）
> 分支：`feat/ai-503`（基于 `feat/ai-502`）

## 1. 目标 / 范围

精炼 `server/src/ai/report-agent.ts` 的 `REPORT_AGENT_SYSTEM_PROMPT`，让每日报告**真正可用、对儿童安全、弱项来自真实错题**：

- **儿童友好、绝不批评**：温暖、具体、像伙伴；禁止恐吓/比较/贴标签（"笨""差""别人都会"类表述）。
- **弱项来自真实错题（核心验收）**：`weakWords` 必须是传入的 `weakWordCandidates`（当日低正确率真实单词）的子集；无候选时给 `[]`；**严禁编造**任何未出现在候选里的单词。
- **mascotExpr 决策规则明确**：有真实进展（完成任务/完成课程/口语分高）→ `cheer`/`happy`；明显吃力（口语分低/任务少）→ `encourage`；中性混合 → `thinking`。

**不新增接口**（backlog 约束）：仅改 prompt + 让"弱项来自真实错题"可满足的 payload 增强（见 §3），不改 `POST /api/ai/report/daily` 契约。

## 2. 为什么需要 payload 增强（关键洞察）

AI-502 的 `callReportAgent` 只把 `DailyReportStats`（纯计数：taskComplete/wordsPracticed/...）喂给模型，里面**没有具体单词**。没有单词数据，模型无法"从真实错题"产出 weakWords，只能编造——直接违反验收。

故 AI-503 在**不新增端点**前提下，于 service 层聚合真实弱项候选 `weakWordCandidates`（详见 §3），随统计一并传给模型；prompt 则强制 weakWords 必须是其子集。这样验收才真正可满足。

## 3. 实现要点

### 3.1 `ai-report.service.ts`（payload 增强，属 AI-503 同 feature 交付）
- `DailyReportStats` 新增 `weakWordCandidates: string[]`。
- `getDailyStats`：`wordProgressRepo.find({ where:{userId, lastPracticedAt: Between}, relations:['word'] })` 已在统计 `wordsPracticed` 时取得；额外推导候选：
  - 过滤 `attempts >= 1 && correctCount/attempts < 0.6`（真实薄弱：练过但常错）；
  - 取 `word.text`，去重，上限 5；
  - 空数组表示当日无明确薄弱单词。
- 口语弱音素属音素级（`AiSpeechAttempt.weakPhonemes`），非单词级，本轮不纳入单词候选（避免音素→单词臆测），在小结文案中已由 speechScore 体现。

### 3.2 `report-agent.ts`（提示精炼，AI-503 主交付）
- 重写 `REPORT_AGENT_SYSTEM_PROMPT`：
  - 角色设定「小狐」儿童英语老师，年龄层约 6–10 岁，语气如伙伴；
  - 输出契约不变（summaryText/weakWords/suggestionText/mascotExpr 严格 JSON）；
  - 新增 `weakWordCandidates` 字段说明：**weakWords 必须从该列表选取，不得超出，无则 `[]`**；
  - mascotExpr 决策规则清单；
  - 安全红线：绝不批评/比较/恐吓，错误用"再试试""我们一起练"表述。
- 文件头注释由「AI-502 落地，AI-503 精炼」改为「AI-503 已精炼完成」。
- `parseReportAgentOutput` 保持现有鲁棒解析（去 code fence、截取 `{`…`}`、字段兜底、`mascotExpr` 非法退 `encourage`）——已满足"输出通过 JSON 校验"验收，不改动。
